> 工作原则：从第一性原理推导问题；方法以“能最好地回答问题”为准，不以本科课程难度或工作量为上限；**所有参数要么从真实数据测得，要么由真实数据训练的模型学到，要么来自可引用的公开研究；三者都没有的未知量，作为条件系统扫描并说明范围，不使用无依据的手设数值。**

## 1. 一句话问题

当用户想**继续关注某个生活议题**，同时**减少其中某一种观点或叙事**时，现有的控制手段能不能做到、能做到什么程度、由什么决定？

例子：一个人仍想看婚恋内容，但不想再被“把个别冲突说成某一性别普遍如此”的视频包围；一个人仍想了解育儿，但不想总看到“严厉管教是唯一出路”。“不感兴趣”、屏蔽关键词、拉黑作者、平台的“内容偏好”滑杆，哪一个能做到，代价是什么？

## 2. 为什么这是值得研究的问题

### 2.1 信息流是对社会的抽样

人们会从信息流里推断“别人怎么想、什么是常态”。推荐排序可以改变这种判断（Brady 等, Nature 2026）；参与度与用户自述偏好并不一致（Milli 等, PNAS Nexus 2025）；同一话题内部的立场会随个性化漂移（Pecher 等, UMAP 2026）。**类别看起来多样，不代表议题内部多样。**我们不需要再证明这些现象存在，它们是本问题的动机。

### 2.2 用户真实的意图往往是“保留议题，调整观点”

用户很少想删掉整个婚恋或育儿话题，他们想减少的是其中某种说法或叙事（Vera & Ghosh 2025 访谈了 14 位 TikTok 用户，记录了他们想清除不想要的推荐、却难以做到的经历；这支持问题情境，但不能估计其普遍程度）。监管也关心议题内部的叙事：网信办 2025 年 9 月部署“清朗·整治恶意挑动负面情绪问题”专项行动，重点之一是挑动群体极端对立情绪；2026 年春节专项通报中处置了“恶意挑动性别对立”的账号。但平台删除是治理手段，用户能否按自己的意愿调整，是另一个问题。

### 2.3 所有补救手段都通过某种“表示”起作用

| 手段 | 作用的单位 |
|---|---|
| 《算法推荐管理规定》第十七条要求的标签选择／删除；快手、抖音、小红书的“内容偏好”滑杆；Instagram “Your Algorithm” | 兴趣标签、类目、话题 |
| 关键词屏蔽、拉黑作者（X 源码中的 muted keyword filter、author socialgraph filter） | 词、作者 |
| “不感兴趣” | 推荐模型对该视频及相似视频的表示（X：Phoenix 预测头与行为序列；快手 OneRec：语义 ID） |
| 外部工具（Compass） | 内容 embedding 相似度 |
| 可控／生成式推荐（UCRS、OneRec 的指令推荐） | 特征、语义 ID、自然语言指令 |

### 2.4 核心原理

**一个控制手段，只能按照它背后的表示能够区分的东西精准起作用。**如果某种表示主要按议题组织内容，同一议题中相反观点的视频彼此很接近，那么基于它的控制在数学上就只能“连带压低整个议题”。用户被迫二选一：忍受倾斜，或者失去这个议题。

因此，“能否保留议题、调整观点”首先不是界面设计问题，而是一个可以测量的问题：**各种表示在议题内部区分观点的能力有多强，以及这种能力怎样转化为控制的精准度。**

### 2.5 一个对偶性质

推荐器若能在表示里区分观点，就能针对个人放大某种观点，也能按负反馈精准地减少它；若不能区分，个性化就无法针对个人放大观点（议题内的倾斜只能来自内容供给或全局热度），负反馈也无法精准纠正。**同一个可测的性质，同时回答“茧房是否由个性化造成”和“按钮能否修复它”。**

### 2.6 范围

- 研究对象是**曝光与控制**。不测量信念、态度或伤害，不判定哪种观点正确，不把“正反均衡”当作目标。
- 用户的调整目标作为明确的测试情境给出，不从匿名日志中推断真实用户的意愿。
- “观点”包括两类属性：对一个命题的**立场**，以及一种**叙事框架**（例如性别对立的以偏概全）。框架对两者都适用。

## 3. 研究问题与假设

**主问题**：当用户想在继续关注某个日常议题的同时，减少其中某一种观点或叙事时，现有控制手段能做到多精准？这种精准度由什么决定？

*When a user wants to see less of one viewpoint or narrative within an everyday issue while continuing to follow the issue, how selectively can existing control mechanisms achieve this, and what determines that selectivity?*

| | 研究问题 | 主要产出 |
|---|---|---|
| **RQ1 测量** | 目标属性（立场或叙事框架）在中文短视频中，能被人和模型多可靠地识别？标题／caption、转录、画面语境分别贡献什么？ | 人工一致性；模型在各工作点上的 TPR、FPR、LR+；可判定比例 |
| **RQ2 表示** | 匹配工具和推荐器所用的表示——文本与多模态 embedding、生产式语义 ID、由真实行为学到的 item 表示——在议题内部编码目标属性的程度，相对于它们编码议题本身的程度有多强？ | 属性对比与议题对比；线性探针；语义 ID 碰撞率；近邻纯度 |
| **RQ3 选择性** | 真实的控制手段——标签／类目压低、关键词屏蔽、拉黑作者、相似度过滤、条件化的 LLM/VLM 过滤，以及 OneRec、序列推荐模型和快手真实日志中的“不感兴趣”——各自带来多少目标减少和连带损失？RQ1、RQ2 的量能否预测它们？ | 控制平面上的 $(\delta_T,\delta_R)$ 与 $S$；与命题 1、2 的预测比较 |
| **RQ4 强度与持续** | 负反馈不断累积时，选择性和议题内构成怎样变化？停止之后会怎样？ | 随反馈次数变化的曲线；与命题 3 的比较 |

假设（结果两种方向都有意义，事先登记，避免看到结果后改写）：

- **H1**：加入转录和画面语境后，属性的可判定比例和模型准确率明显提高；隐含、反讽、剧情台词是主要错误来源。
- **H2**：在通用 embedding 和生产式语义 ID 中，议题对比远大于属性对比；同一议题内属性相反的视频共享语义 ID 前缀的比例，接近属性相同的视频。
- **H3（双向）**：由真实行为学到的表示是否编码属性，取决于受众是否按该属性分化。
- **H4**：标签级控制的 $S\approx0$；关键词屏蔽因引用和反讽而 LR+ 偏低；拉黑作者的 $S$ 由作者属性纯度决定；相似度过滤 $S$ 偏低；条件化 LLM/VLM 过滤 $S$ 最高；学习型负反馈的 $S$ 接近由模型自身表示给出的命题 2 预测。
- **H5**：累积负反馈使议题内目标占比下降，但议题整体曝光下降更快，$S\to0$（命题 3）。
- **H6**：上述排序在留出议题和留出属性上仍成立。

## 4. 理论框架

### 4.1 定义

记号：全部视频 $\mathcal I$；议题 $k$；用户 $u$ 的曝光分布 $\pi_u$，$\pi_u(G)=\sum_{i\in G}\pi_u(i)$。

1. **议题语料** $I_k=\{i\in\mathcal I:\mathrm{rel}_k(i)=1\}$。$\mathrm{rel}_k$ 由标注规范判定，检索近似的查准率和查全率单独测量。
2. **目标属性** $s:I_k\to\{+,\,-,\,0,\,?\}$：$+$ 具有目标属性（例如支持命题、使用性别对立叙事），$-$ 具有相反属性，$0$ 相关但不涉及，$?$ 无法判断。立场任务可细分出“有条件支持”。
3. **观点曝光** $\mathrm{VE}_u=(m_u,p_u,q_u)$：
   $$m_u=\pi_u(I_k),\qquad p_{u,\sigma}=\frac{\pi_u(\{i\in I_k:s(i)=\sigma\})}{\pi_u(I_k\setminus I_k^{?})},\qquad q_u=\frac{\pi_u(I_k^{?})}{\pi_u(I_k)}$$
   熵 $H(p_u)$ 描述集中程度，$\mathrm{JS}(p_u,p^{\mathrm{ref}})$ 描述与明确参照的差异；两者都只是描述量。
4. **目标集与保留集** $A=\{i\in I_k:s(i)=+\}$，$B=\{i\in I_k:s(i)\in\{-,0\}\}$。用户的意图是“减少 $A$，保留 $B$”。$I_k^{?}$ 单列，用最好和最坏情形给出结论的范围。
5. **保留系数** $g_a(i)=\pi^a(i)/\pi(i)$，$\bar g_a(G)=\pi^a(G)/\pi(G)$。
6. **目标减少、连带损失与观点选择性**
   $$\delta_T(a)=1-\bar g_a(A),\qquad \delta_R(a)=1-\bar g_a(B),\qquad S(a)=1-\frac{\delta_R(a)}{\delta_T(a)}$$
   $S=1$ 只减目标；$S=0$ 整个议题等比例压低；$S<0$ 误伤多于命中。$S$ 是比值，$\delta_T$ 很小时不稳定，所以总是同时报告 $(\delta_T,\delta_R)$ 及置信区间。
7. **控制平面**：横轴 $\delta_T$、纵轴 $\delta_R$。对角线 $\delta_R=\delta_T$ 对应 $S=0$，理想点为 $(1,0)$。每种手段是平面上的一个点，或一条随强度、阈值变化的曲线。

### 4.2 分析结果

- **命题 0（标签级控制）**：若控制对议题内每条视频的保留系数相同，则 $S=0$；一般地，$S=0\iff\bar g_a(A)=\bar g_a(B)$。只按标签、类目或话题起作用的“破茧”功能，除非标签本身对应某种属性，否则在观点层面的选择性恒为 0。
- **命题 1（分类式过滤）**：删除被判为 $+$ 的视频且不回填时，$\delta_T=\mathrm{TPR}_\pi$，$\delta_R=\mathrm{FPR}_\pi$（按曝光加权），所以 $S=1-\mathrm{FPR}_\pi/\mathrm{TPR}_\pi=1-1/\mathrm{LR}^+$，这类手段的控制曲线就是曝光加权的 ROC 曲线。关键词、作者、相似度、LLM/VLM 判断都属于这一类，区别只在于判断从哪里来。
- **命题 2（embedding 推荐器中的负反馈，一阶）**：点积打分、softmax 曝光，点踩视频 $j$ 后用户向量沿 $-v_j$ 小步更新。记 $s_j(i)=\langle v_j,v_i\rangle$，$\bar s_j(G)$ 为 $G$ 内按曝光加权的平均，$\bar s_j$ 为整个信息流的平均，则
  $$S_{\mathrm{fb}}\approx\frac{\bar s_j(A)-\bar s_j(B)}{\bar s_j(A)-\bar s_j}$$
  分子是属性对比，分母是目标对比。一阶下 $S$ 与步长和温度无关：点得越多，目标和连带损失只会同比例放大。
- **命题 3（反馈强度的代价）**：在同一模型下，令累积强度 $\kappa$ 增大，$\pi^\kappa(i)\propto\pi(i)e^{-\kappa s_j(i)}$。只要 $A$ 内的平均相似度保持高于 $B$，议题内目标占比 $p_+$ 随 $\kappa$ 单调下降；但只要议题整体比议题外内容更接近被点踩的视频，当 $\kappa\to\infty$ 时 $\bar g(A),\bar g(B)\to0$，所以 $\delta_T,\delta_R\to1$，$S\to0$。**反复点“不感兴趣”会让议题内的观点构成变好，但代价是整个议题从信息流中消失。**这与用户常说的“点多了整个话题都没了”一致，而且可以在真实模型上检验。
- **注记（对偶性）**：若议题内属性与 item 表示相互独立，则对任何用户，$\mathbb E[\pi_u(A)/\pi_u(I_k)]$ 等于供给中的属性比例：个性化不能针对个人放大该属性，负反馈也无法精准减少它。

## 5. 研究空白与贡献

| 研究 | 测了什么 | 没有回答什么 |
|---|---|---|
| Kaplan 等 2026（TikTok） | “不感兴趣”与划走后话题占比的下降和复发 | 同一话题内其他内容是否被连带减少；话题内的观点 |
| Wang 等 RecSys 2023（Google） | 点踩后同簇、同作者推荐的减少（responsiveness） | 用户仍想要的内容是否受损；观点 |
| Mozilla 2022（YouTube） | 拒绝后相似视频是否仍被推荐 | 连带损失；观点 |
| Pecher 等 2026 | 同话题内的立场漂移 | 控制能否纠正漂移 |
| Compass 2026 | 反思偏好、embedding 匹配过滤，15 人十天实地研究 | 偏好均为话题级；作者承认 embedding 可能抓不住意图与风格；未测误删 |
| UCRS 2022；OneRec 2026 | 可控推荐、指令推荐 | 是否能执行“保留议题、调整观点”这类指令 |
| Göpfert 等 2022；Waller & Anderson 2021；EMNLP 2024 立场感知句向量 | 表示中能否找到软属性、党派维度；通用句向量难以区分同话题相反立场 | 日常议题内的观点是否被推荐表示编码，以及对控制意味着什么 |

**空白**：已有研究要么证明了议题内的观点漂移存在，要么测量了控制手段能减少多少目标内容；**没有研究把“同一议题内用户仍想要的内容是否被保留”当作结果变量，也没有研究控制能否区分观点由什么决定。**

**贡献**：

1. **问题与框架**：把“保留议题、调整观点”形式化为可测量的选择性，用一个控制平面比较所有手段。
2. **分析结果**：选择性与分类器的 LR+、表示几何之间的关系，以及“反馈越强、议题越空”的代价（命题 1–3）。
3. **语料**：中文短视频议题内观点与叙事的人工金标准语料，含标题／caption、转录、画面三种输入条件。
4. **表示测量**：在生产式语义 ID（OneRec）和真实行为学到的表示上，测量日常议题内的观点是否被编码。据我们检索，尚未见到这类测量，文献核查会在执行中继续扩展。
5. **控制测量**：在同一平面上测量真实控制手段的选择性，包括快手真实用户“不感兴趣”事件和 OneRec 的反事实实验。
6. **可用结论**：用户、工具开发者和监管者分别能期待什么；一个观点级工具需要达到怎样的 LR+。

## 7. 研究设计

### WP1 议题与属性的发现（RQ1 前置）

不预先拍定命题，而是从语料里找。对 RecIF caption 和 ShortVideo ASR，用关键词与语义检索召回候选议题内容，用 LLM 归纳反复出现的命题和叙事框架，按事先登记的标准选择：两种属性都有足够内容；与日常判断相关；可以从内容中判定；有足够曝光记录。预检已经显示：许多命题在供给上一边倒（如“彩礼该不该要”几乎没有支持方），而性别对立这类叙事框架反复出现。**候选：婚恋议题中的性别对立叙事（主），育儿或职业议题中的一个双边命题（次），另一个议题留出。**

### WP2 金标准语料（RQ1）

- 标注规范：属性定义、判定顺序、引用／反讽／剧情台词等特殊情况、证据片段。
- 两名成员独立标注，第三人裁决；报告 Krippendorff's α 与分歧类型。
- 分层抽样：用模型预打分加权抽样以保证 $A$ 类数量，再用逆概率加权估计总体量。
- 样本量依据：$S=1-\mathrm{FPR}/\mathrm{TPR}$ 的方差可用 delta 方法估计；在 TPR≈0.8、FPR≈0.1 时，$A$、$B$ 各约 200 条，$S$ 的 95% 区间约为 ±0.05。每个属性的目标是至少 200 条 $A$ 和 200 条 $B$。

### WP3 内容理解与工作点（RQ1）

- 输入条件：标题／caption、加转录、加画面帧（ShortVideo 子集；VLM 如 Qwen3-VL）。
- 模型：开源模型（Qwen3 系列，可复现）与一到两个前沿 API 模型；零样本与少样本；输出标签、证据和置信度。
- 指标：混淆矩阵、各类 precision/recall、按置信度变化的 TPR/FPR 曲线、LR+、拒答—覆盖曲线；按曝光加权的版本使用 RecIF 曝光量。

### WP4 表示分析（RQ2）

- 表示：Qwen3-Embedding（0.6B/4B/8B）、BGE-M3 等文本 embedding；Qwen3-VL-Embedding；ShortVideo ViT 特征；RecIF 语义 ID；OneRec 的语义 ID token 表示和隐藏状态；在 RecIF/KuaiRand 上训练的序列推荐 item 表示。
- 指标：属性对比、议题对比（自助法置信区间）；线性探针 AUC；同议题内属性相同、相反视频共享语义 ID 前缀的比例；$k$ 近邻属性纯度。

### WP5 过滤类手段的选择性（RQ3，命题 0、1）

在金标准语料上，按曝光加权计算各手段在控制平面上的点和曲线：真实类目标签（KuaiRand、ShortVideo）；关键词屏蔽（用户会自然选择的词，事先登记）；拉黑作者（作者属性纯度来自 KuaiRand 作者字段）；相似度过滤（以属性描述或示例为查询，扫描阈值）；条件化 LLM/VLM 过滤。

### WP6 学习型负反馈（RQ3、RQ4，命题 2、3）

- **OneRec 反事实**：保留真实用户的历史上下文，在“不感兴趣”一栏分别加入 $A$ 类、$B$ 类、议题外视频（1 到 10 条），计算模型对候选集合中各语义 ID 的概率，得到 $(\delta_T,\delta_R)$、$S$ 和随次数变化的曲线；用 OneRec 自身的 item 表示计算命题 2 的预测并比较；比较 1.7B 与 8B。
- **训练的序列推荐模型**：在 RecIF、KuaiRand 上训练带行为类型（含不感兴趣）的序列模型，做同样的反事实。
- **指令控制（可选）**：用自然语言向 OneRec 表达“少看某种叙事、保留议题”，测量它能否执行。

### WP7 真实日志事件研究（RQ3）

在 RecIF（以及 KuaiRand-27K 复现）中，以用户对议题视频点“不感兴趣”为事件，比较事件前后议题内 $A$、$B$ 曝光的变化；用相同位置上看到同类视频但没有点的用户作匹配对照，做双重差分，检验事前趋势。这给出**快手真实系统**上的经验 $(\delta_T,\delta_R)$。它是观察性证据：用户自己的兴趣变化与平台响应混在一起，匹配对照只能部分分离，报告中照此表述。

### WP8 强度与持续（RQ4）

用 OneRec 作为推荐器、用在真实日志上训练的响应模型预测用户行为，做多步滚动：累积负反馈、停止负反馈、恢复原有观看。所有转移都来自学到的模型；唯一由研究者给定的是情境（目标属性和操作序列），并作为实验条件报告。

### WP9 综合与交付

控制平面总图；按手段给出可达的选择性和代价；观点级工具所需的 LR+；跨议题、跨属性的稳健性；局限。可选：用表现最好的手段做一个可演示的选择性过滤原型，并报告它自身测得的 $S$。

## 8. 资源档位

| | 理想 | 平衡 | 最低 |
|---|---|---|---|
| GPU | 1×A100/H100 80GB，约 100–200 GPU 小时 | 1×24GB（4090/A10/L4），约 60 GPU 小时 | 云端 T4 16GB 或 Colab，约 20 GPU 小时 |
| LLM API | 2–3 个前沿模型做标注对比，约 300–1,000 美元 | 1 个前沿模型加 1 个低价模型，约 100–200 美元 | 低价模型（如 DeepSeek、Qwen），约 20–50 美元 |
| 人工标注 | 3 个属性 × 每属性约 800 条双标加裁决，约 120–150 人时 | 2 个属性 × 约 500 条，约 60–80 人时 | 2 个属性 × 约 300 条，约 30–40 人时 |
| 模型 | OneRec-8B 与 1.7B；Qwen3-Embedding-8B；Qwen3-VL-8B | OneRec-1.7B 为主，8B 抽样复核；embedding 0.6B/4B | OneRec-1.7B；embedding 0.6B；不做画面 |
| 数据 | RecIF、ShortVideo 全量 ASR 与标注子集的视频、KuaiRand-27K | RecIF、ShortVideo ASR、KuaiRand-1K | RecIF、ShortVideo ASR |
| 存储 | 约 150 GB | 约 60 GB | 约 30 GB |

**现有条件**：服务器 `tyu-g1` 有 8×A6000 48GB，GPU 已超过理想档；限制在磁盘，共享盘只剩约 149GB，所以数据只取实际需要的部分，KuaiRand-27K 视需要再下载。LLM API 与人工标注规模仍待决定。

降档会损失什么：

- 没有前沿 API：只能给出开源模型能达到的选择性，“观点级工具最好能做到多好”的上界变弱。
- 没有 VLM：无法回答画面语境的贡献（RQ1 的一部分）。
- 没有 8B 模型：缺少模型规模的稳健性检查。
- 标注量减少：$S$ 的置信区间变宽，按上面的公式，每类样本减半，标准误约放大到 1.4 倍。
- 属性或议题减少：H6 的泛化检验变弱。

估算依据：生产式语义 ID 已随 RecIF 提供，无需自己运行 Qwen3-Embedding-8B 编码 RecIF 视频；OneRec 反事实可以共享上下文前缀缓存，每个上下文只需一次前向；主要的 GPU 开销来自大规模 LLM 筛选、序列模型训练和 VLM。

## 10. 风险与卡点

| 风险 | 状态 | 应对 |
|---|---|---|
| 两种属性的内容都要足够 | 预检显示 ShortVideo 中多数命题稀少且一边倒；RecIF 规模大 100 倍，正在核查 | WP1 以数据发现属性；叙事框架作主属性 |
| 观察性事件研究的混杂 | 设计层面已识别 | 匹配对照、双重差分、事前趋势检验；结论表述为关联加模型反事实的互证 |
| RecIF caption 的信息量 | 核查中 | 不足时，用 ShortVideo 的 ASR 与画面补充测量，或对 RecIF 的标注子集补充人工判断 |
| OneRec 不按预期使用不感兴趣上下文 | 训练数据确含该上下文 | 先检验模型对加入议题外视频是否有反应，作为操纵检验 |
| 语义 ID 碰撞使候选概率无法区分视频 | 已测得 12.7% 的视频共用完整语义 ID | 这本身是结果的一部分；候选集合按语义 ID 去重后计算 |
| 生成式模型不等于平台生产系统 | 设计层面 | 结论表述为“这一类机制”；真实日志事件研究提供平台层面的证据 |

## 11. 与 v3 和组员方案的关系

v3 的生活动机、资源调研和文献核查保留；它的研究问题偏向产品流程，且包含大量未经验证的设定。组员方案的 RQ 更易读，但仿真中负反馈的选择性被直接设定为参数，结论由参数决定。本计划把这两处都换成测量：选择性来自真实表示、真实模型和真实日志。
