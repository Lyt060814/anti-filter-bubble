# Research Plan v6：我们刷到的对立叙事——短视频议题中的观点茧房与逃离的代价

2026-11-07 · 取代 [v5](research_plan_v5.md) 的范围与分工；v5 的定义、命题和可行性结果全部沿用。三人分工与协作方式见 [docs/tasks](../tasks/README.md)。

## 0. 定位

- **叙事框架**：我们是大学生，每天在短视频里刷到性别婚恋、身材外貌、出路选择、消费观等议题上的争吵。题目和报告用这个视角讲故事。
- **研究对象**：以数据为核心。数据是快手的公开日志和推荐模型，覆盖一般用户，不限于大学生；"大学生"只用于选择和组织议题，不是研究对象本身。
- **性质**：课程项目，体验完整的科研流程，不提交代码。凡是数字，要么来自实际运行，要么明确标为"情境假设"，并通过参数扫描报告整条曲线。

## 1. 研究问题

**主问题**：短视频上的议题争论里，推荐会不会让一个人在保留话题的同时，越来越多地看到某一种对立叙事？他能察觉吗？他能用的办法要付出多大代价？

| | 问题 | 范围 | 证据 |
|---|---|---|---|
| **RQ1 分布** | 各大类议题上，对立叙事有多常见？是哪几种类型？它们是否更容易获得互动？ | 全部大类 | 快手日志 + LLM 标注 + 人工核查（实测） |
| **RQ2 形成与察觉** | 偏好某种叙事的用户，推荐会让他的议题内观点偏多少、多快？要看多少条视频才能察觉？ | 案例：性别与婚恋，"群体标签"叙事 | OneRec 实测 + 透明模型模拟（情境参数） + 样本量计算 |
| **RQ3 逃离** | "不感兴趣"、多看另一类内容、删除历史、屏蔽、关闭个性化等，各自能把偏斜降多少？代价和持续时间如何？哪些偏斜靠用户自己去不掉？ | 同上 | 同上 |

## 2. 议题分类（两层）

大类 → 具体议题，另加一个横跨所有大类的"叙事类型"维度。大类和议题以[自下而上的抽样结果](../../analysis/v6/README.md)为准，下表是初稿。

| 大类 | 具体议题（例） | 关键词初筛的曝光占比 |
|---|---|---|
| 性别与婚恋（**案例研究**） | 婚恋、择偶标准、生育意愿、性别期待 | 2.0% |
| 身体与外貌 | 容貌焦虑、减肥、医美 | 1.5% |
| 家庭与代际 | 育儿与教育、养老、啃老 | 0.4% + 0.4% |
| 人生选择与出路 | 考研考公 vs 闯荡、绩点 vs 实习、留学、躺平 vs 奋斗 | 约 0.2% |
| 消费与经济 | 消费观、理财与房价 | 约 0.2% |

叙事类型：**唯一正确**（把一种选择说成唯一正道）、**二元对立**（非此即彼）、**焦虑渲染**（用恐惧推动观点）、**群体标签**（给一类人整体贴负面标签）。爱国、历史、言论边界、校园管控等政治敏感议题不纳入：标注分歧大，伦理和公开讨论都难处理。

## 3. 理论（沿用 v5 第 4 节，补一层）

- 用户状态 $(m,V)$：$m$ 是议题占比，$V=\operatorname{logit}p_u-\operatorname{logit}\bar p$ 是议题内目标叙事相对平台平均的偏斜。
- 偏斜分三层：**供给**（平台上本来有多少，只描述、不评判）、**平台排序放大**（$\operatorname{logit}\bar p-\operatorname{logit}p^{\mathrm{sup}}$，所有人共有）、**个人茧房**（$V_u$）。主结果同时报告总偏斜和 $V$，否则会漏掉平台整体的偏移。
- 命题 0–4 照旧，新增一条：**用户侧操作能降低的偏斜，上限是个人这一层**。关闭个性化让 $V$ 归零，但平台层面的偏移还在；以"关闭个性化"模式为参照的察觉，也只能发现个人这一层。
