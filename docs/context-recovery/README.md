## 1. 首次恢复时的研究方向（历史记录）

最新讨论的核心可以概括为：**短视频推荐与用户自己认可的信息饮食发生偏离时，用户能否看见偏离、有效调整，以及需要付出多少操作和内容机会成本，调整后是否反弹？**

- **Q1 镜子**：分别描述主题分布、特定议题内的立场分布；说明与什么参照比较，并呈现重复、持续性和测量不确定性。主题窄不自动等于有害；不规定所有用户都必须多样，也不把立场强制调到 50:50。
