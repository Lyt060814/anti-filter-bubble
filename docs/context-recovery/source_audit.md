## 1. ShortVideo、SimTok 和清华研究不是同一资源

| 来源与阅读程度 | 复核所得 | 对项目的影响 |
|---|---|---|
| [ShortVideo_dataset 官方仓库](https://github.com/tsinghua-fib-lab/ShortVideo_dataset)，README；[数据论文全文](https://arxiv.org/abs/2502.05922) | Yu Shang、Chen Gao、Nian Li、Yong Li，WWW 2025 Companion；数据有层级类目、文本及多模态表征，公开抽样与需申请的版本不同 | 先报告实际使用版本，不能把论文全量规模写成当前样本规模 |
| 用户最后附件 [SimTok / 2504.08742](https://arxiv.org/abs/2504.08742)，全文 | *Simulating Filter Bubble on Short-video Recommender System with Large Language Model Agents*；20 个模拟用户与另一个短视频语料的实验 | 它**不是**上述 dataset 的介绍论文；没有充分证据把两套数据认作同一套 |
| [Deep Filter Bubble](https://arxiv.org/abs/2403.04511)，摘要、定义/方法关键段及仓库深读笔记 | 深层类目内部的覆盖不足可以与顶层广泛兴趣共存；仍是类目层面的度量 | “细粒度类别”不等于“观点立场”，数据也不自动等于公开 ShortVideo 样本 |
| [Piao 等原始代码](https://github.com/tsinghua-fib-lab/Adaptive-Information-Dynamic-Model)，官方来源定位及仓库既有深读 | 相似匹配、正负反馈、相对多样性的模型谱系 | 本次未重新完整复现论文/全部源码；保留为机制参考，不能把其参数当成平台真实值 |

本仓库 ShortVideo pilot 去重后 6,654 用户、31,496 视频、129,483 事件；用户事件数中位数仅 10，时间间隔中位数约 819 秒。一个交互可能被多个类目/标签展开成多行，需要先按事件去重。它适合内容和人口学描述，但很难支撑连续完整 feed 的事件研究。全量可访问性、原始视频和 ASR 的实际供给方式应逐文件确认，不能由论文“有多模态”推导出本地已取得视频。

## 2. 快手数据：随机化的对象必须说准

已检查 [KuaiRand 官方站](https://kuairand.com/)、[KuaiRec 官方站](https://kuairec.com/)，并补读 [KuaiRand 论文数据采集段](https://arxiv.org/abs/2208.08696) 与 [KuaiRec 论文数据采集段](https://arxiv.org/abs/2202.10842)。

- KuaiRand 从 7,583 条筛选池中均匀抽视频，随机替换推荐列表中的曝光。**0.37% 是随机替换曝光占比，不是候选池占全库的比例。** 全集随机干预期为 2022-04-22 至 05-08，历史期另取此前两周。日志含多个场景/tab，不能直接统称一个同质的短视频首页流。
- 被随机化的是视频曝光，用户点 hate/follow 仍是自选择。事件后同类内容减少可以受均值回归、活动量、其他行为、时间和推荐场景影响；对照与前趋势提高可信度，但不会自动获得随机按钮试验的因果识别。
- `is_hate` 的官方字段说明是 hated video；仅凭字段名不足以锁定当年的具体 UI、事件去重语义或等同所有平台的“不感兴趣”。
- Pure 只保留有限物品池上的部分历史。将被筛掉的曝光当不存在，会扭曲窗口长度、类目比例、事件前后时序。因此最新主线选择 1K 有道理，但要重新溯源其事件数据。
- KuaiRec 小矩阵 1,411 × 3,327、99.6% 是特定用户与物品池的稠密观测；原采集含约 15 天强制补曝光，余下缺失与屏蔽作者有关。其 watch ratio 是行为代理，可能超过 1；不是真实满意度或每个用户原本自然 feed。
- KuaiRec 论文的代表性检验覆盖有限人口/物品属性，不能据“不拒绝同分布”推出对全部内容/观点分布的全面代表性。
- 新增标题/层级类目文件要与旧 tags、原日志分别标版本。模型生成类目与旧标签的一致率不是主题真值准确率，更不是立场准确率。数据及补充文件的授权条款应分别引用。

[类目映射](../../analysis/data_check/category_map_l1.csv) 已明确 41 个原始索引映到 34 个统一主题；不要跨数据集直接按整数 ID join。接受度曲线用过去历史排序类别、后续随机曝光算 long-view；“排名 4–10 为首位的 77%”是特定样本/指标，不是任何新内容都能保留 77% 满意度。

## 3. X：固定源码版本，区分机制与线上行为

本次获取并检查了 [`xai-org/x-algorithm@b79b947ce9283c786822274ef8fe208c33c585b2`](https://github.com/xai-org/x-algorithm/tree/b79b947ce9283c786822274ef8fe208c33c585b2)，结合仓库代码地图核查参数、打分和关键过滤路径；**未声称审计完整 X 全仓或线上部署**。

| 问题 | 更准确的解释 |
|---|---|
| NI −47.52，like 等权重 | 系数乘的是预测动作概率，不是一次点击直接扣 47.52 分；不能用权重比直接换算用户需要点几次 |
| 源码没有 NI hard filter | 只约束已检查路径；不证明全服务没有别的移除、缓存或上游处理 |
| “只有关键词能硬排主题” | [`TopicIdsFilter`](https://github.com/xai-org/x-algorithm/blob/b79b947ce9283c786822274ef8fe208c33c585b2/home-mixer/filters/topic_ids_filter.rs) 还处理 `excluded_topic_ids`；启用时匹配被排除 topic 的候选会移除，无 topic 标签候选也会移除。它与普通用户 UI 如何连接仍未知 |
| 30 天 TTL / 1024 长度 | 某项存储 TTL、某个序列窗口都不能直接等于系统全部记忆长度 |
| DPP、探索默认值 | 能说明这个源码快照的默认配置，不能证明所有用户线上同时启用 |
| 用快手数据补 X action heads | 是跨域 surrogate；字段语义、缺失动作头处理和校准需列为假设，缺失设 0 并非已证无影响 |
| 新参数已同步 | 文档更新不等于旧 `sim.py` 和全部结果已更新；后续应显式标记模型版本并重算 |

X 只为新方案提供机制依据。KuaiRand 提供快手 2022 的观察数据，仿真提供给定假设下的可控对照；三者不能拼成“已验证真实抖音/快手算法”的证据。

## 4. 用户控制研究：不是同一个百分比或同一种复发

| 一手来源 / 本次阅读程度 | 应保留的事实与限定 |
|---|---|
| [Liu、Wu、Resnick 2024](https://ojs.aaai.org/index.php/ICWSM/article/view/31363)，论文页/方法信息与既有笔记 | 约 88% 是特定 YouTube homepage unwanted-topic 实验的抑制结果，不是所有界面与真人整体成功率；官方代码是 [youtube-disinterest](https://github.com/avliu-um/youtube-disinterest) |
| [Kaplan 等 2026](https://arxiv.org/html/2605.10690v1)，全文 | 15 次实验来自 3 主题 × 5 重复，并不是 15 个账号；一次实验多账号。先用 25 个搜索主题视频初始化。后续 relapse 阶段重新对目标主题表现正向观看，不宜简写为“只要停止按按钮就自然复发”；未初始化的 all-skip 账号也不等于关闭个性化 |
| [Mozilla 2022](https://assets.mofoprod.net/network/documents/Mozilla-Report-YouTube-User-Controls.pdf)，本次以仓库已有报告笔记为主，未重新全文逐页核查 | 约 11% 与特定相似 unwanted 推荐对的避免有关；不能与另一篇 88% 直接组成“同一按钮结论冲突”的效果量对比 |
| [Li、Chhabra、Wojcieszak 2026](https://ojs.aaai.org/index.php/ICWSM/article/view/42704)，官方摘要/元数据核实 | 18 条件，每条件 1,000 puppets，30 轮，Homepage 与 Up-Next；Downranking 效果较稳定、界面差异明显。不能称为测了真实用户主观满意度，也不能将它直接等同原生 NI 按钮 |

应做“平台 × 界面 × 操作 × 目标内容 × 剂量 × 观察时长 × 后续行为 × 结果定义”的对照表。百分比不可直接横排成统一排行榜。

## 5. 新主线的概念、度量与标注

- [Kleinberg、Mullainathan、Raghavan](https://arxiv.org/abs/2202.11776)，核实官方摘要：行为选择与用户认可的愿望可能不一致；即使平台以用户效用为目标，仅凭 engagement 也存在识别问题。它不证明所有用户都后悔，也不让我们直接从日志读出认可偏好。
- [Gauthier 等 Nature 2026](https://www.nature.com/articles/s41586-026-10098-2)，原文摘要、设计与机制段：这是 **2023 年进行、2026 年发表的随机现场实验**，主分析完成样本 4,965；开/关算法存在不对称，关注列表变化是机制线索。论文没有发现显著的党派认同或情感极化变化，不能泛化成“算法已证使所有人极化”，也不是检验本仓 X 2026 代码的实验。
- [Milli 等 2025 原文入口](https://pmc.ncbi.nlm.nih.gov/articles/PMC11894805/) 本次遇到访问验证，另一出版页未成功打开；保留仓库笔记，**不升级为本次完整原文核实**。下一次引用“用户不喜欢”时要区分政治帖子与全部帖子、样本和比较设置。
- [RADio*](https://doi.org/10.1145/3636465)，度量方法段；[Draws 等 nDJS](https://ujwalgadiraju.com/Publications/Bias2020.pdf)，公式段：分布差异的含义由参照和规范目标决定；增加 divergence 并不在所有目标下都更坏。base-2 JS 有界，平方根 JS 才满足距离度量的三角不等式。
- [C-STANCE](https://aclanthology.org/2023.acl-long.747/)，官方论文/标注与局限关键段：立场始终相对于明确 target；不能把主题、情绪、立场混用。
- [DGTA](https://arxiv.org/abs/2601.19802)，官方摘要核实；[C-MTCSD](https://arxiv.org/abs/2504.09958)，官方摘要/资源定位：某一设置的约 .64 F1 **不是中文零样本立场识别的通用上限**。目标识别与立场分类的分数也不能混写。
- [TikStance](https://arxiv.org/abs/2607.15240)，官方摘要核实：161 视频、13,876 评论；最终 α 约 .722–.743，包含多模态和对话上下文。它给出标注流程参照，不是纯标题跨域性能保证。

**关键尚未解决的可行性问题**：标题未必表达完整视频立场。若大量内容只能标“证据不足”，观点维度可能需要缩小范围或改换内容源。因此不能继承 execution plan 的“缺画面不影响主结论”。κ≥.6 是项目建议门槛，不是正确性证明；需报告类别分布、分项表现与弃判率。

## 6. 模拟器谱系保留什么

本次结合原论文关键段和仓库已有深读检查了 [CIRS](https://arxiv.org/abs/2204.01266)、[DORL](https://arxiv.org/abs/2307.04571)、[BEP](https://arxiv.org/abs/2512.03067)，没有重新训练它们。

- CIRS 的反事实奖励和 KuaiEnv 的满意度/离开规则是模型与环境构造；避开重复类别的策略若正好绕开规则，不足以证明真实用户满意度改善。
- DORL 关注离线 RL 的保守性与热门类别集中。可帮助解释“只按历史优化”的局限，不是用户按钮效果的直接证据。
- BEP 将不同用户行为倾向下的曝光作对比，正/负行为是论文特定定义，不等于平台 `is_hate`；其 LLM 用户也需要行为验证。
- SimTok 是概念性模拟参考。少量虚拟用户、人工行为规则与相对阈值不足以建立对真实短视频用户的外推保证。

本仓先导试验给出了不把 LLM 用户放在主线的务实理由；这不需要夸大成对上述全部研究的否定。
