## 1. 真实曝光的结构（`recif_user_item_stats.py`）

议题取婚恋与家庭，按 15 个关键词（离婚、婆媳、婆婆、女方、男方、家暴、出轨、AA制、彩礼、结婚、婚姻、相亲、夫妻、老公、老婆）在生成描述中检索候选。命中只是候选，不等于相关。

| 量 | 结果 |
|---|---|
| 议题候选视频 | 260,566 条，其中 229,300 条在日志中出现过 |
| 议题曝光 | 1,515,814 次，占全部 75,671,142 次曝光的 2.0% |
| 每个用户的议题曝光次数 | 中位数 8（p10 3，p90 17，p99 40）；≥10 次的用户 60,909 人，≥20 次 11,343 人，≥50 次 813 人 |
| 每个用户的议题占比 | 中位数 1.6%（p10 0.6%，p90 3.6%） |
| 每条议题视频的曝光次数 | 中位数 1；≥5 次 37,240 条，≥20 次 10,317 条，≥50 次 4,282 条 |
| 议题视频的反馈率 | 看完 34.6%，点赞 5.2%，不感兴趣 0.086%（全体分别为 26.7%、7.2%、0.071%） |

**含义**：单个用户的议题曝光很少，个人层面的 $V$ 只能在模拟中精确计算，真实日志只能做总体层面的检验。按物品 ID 学习的模型能为约 1–4 万条议题视频学到可靠表示，冷门视频要靠内容表示。

## 2. 目标叙事的初步信号（关键词代理，不是标签）

用明显的标签词和以偏概全句式（捞女、凤凰男、扶弟魔、妈宝男、普信男、女拳、田园女权、"女人都""男人都"等 18 个）作为"把个案归结为性别特征"的粗代理：

| 量 | 结果 |
|---|---|
| 同时命中议题与代理词的视频 | 364 条，曝光 2,428 次，占议题曝光的 0.16% |
| 代理视频的反馈率 | 看完 35.8%，点赞 **8.0%**，不感兴趣 0.041% |
| 同议题其他视频 | 看完 34.6%，点赞 **5.2%**，不感兴趣 0.087% |

点赞率之差约 2.8 个百分点，约为抽样标准误（0.55 个百分点）的 5 倍。方向支持 H1a：这类叙事更容易获得互动，按互动排序会放大它。代理只覆盖明显的说法，LLM 标注会找到更多隐含表达（第 5 节）。

**用户间离散度**（议题曝光 ≥10 次的 60,909 名用户）：代理视频在每人议题曝光中的占比，beta-二项离散系数 $\rho=0.0042$；二项基准的 95% 分位为 0.0009，保持每人曝光数不变的置换基准为 0.0010。议题占比本身的离散系数为 0.0105（基准约 0）。真实用户看到这类叙事的比例确实因人而异，且超出随机，支持 H1d。尚未控制时间等混杂因素，正式分析要用时间匹配的置换基准。

## 3. OneRec 的输入格式

| 任务 | 输入 | 对模拟的意义 |
|---|---|---|
| 视频推荐（video_test，38,781 条） | 只有语义 ID 序列，中位数 485 条、最多 512 条，不带行为类型；输出后续 10 条 | 适合做形成与持续性；用户的反馈类型无法表达 |
| 条件推荐（label_cond_test，34,891 条） | 分栏历史：看完、点赞、关注、转发、不感兴趣，**每栏最多 10 条**；7.2% 的样本含"不感兴趣"栏 | 适合做反馈类策略；只记住每类最近 10 条 |
| 反应预测（label_pred_test，346,190 条） | 分栏历史加一条候选，回答"是/否" | 可作为备选的用户反应模型（报告的 AUC 为 0.62） |

OpenOneRec 技术报告：语义 ID 来自视频文本描述的 Qwen3-Embedding-8B 向量，经 3 层、每层 8,192 个码的残差 K-means 量化，未说明加入行为信号；测试用户（20%）完全不参与训练。所以模拟的种子用户取测试集。

**补充**：公开的日志文件（162,074 名用户，`split` 全为 0）只含训练用户；基准测试用户的 uid 不在其中，他们的历史只出现在基准文件里。所以 OneRec 的种子用户取基准测试集，真实日志的统计（第 1、2 节）都是训练用户。

### 3.1 操纵检验（`onerec_manipulation_probe.py`，OneRec-1.7B，GPU 0）

- **模板**：不开思考模式时，99.9% 的输出是合法语义 ID 格式；开思考模式时几乎全部输出文字推理。随后都用不开思考的模板。采样得到的语义 ID 中，68%–80% 对应目录中实际存在的视频，其余是不存在的编码组合。
- **抽样召回**：在 60 条条件推荐基准样本上，64 次采样的召回率为 1.1%（模型卡报告的 Recall@32 为 1.84%，生成方式未说明；量级相符）。
- **精确打分**：用共享前缀缓存逐层计算三层语义 ID 的概率，2,000 条候选在条件推荐提示上用时 1.4 秒，在 500 条历史的视频推荐提示上用时 7.6 秒；真实的下一条视频在 2,000 条随机视频中排第 1，视频推荐任务的 10 条真实目标排在前 12 名以内。模拟中可以用精确概率代替采样。

40 名测试用户，每个条件采样 2,000 条推荐，$m$ 为推荐中议题视频的比例：

| 条件 | $m$ 均值 | 与对照相比 |
|---|---:|---|
| 原始历史 | 2.6% | |
| 看完栏换成 10 条议题视频 | 5.7% | 比换成 10 条非议题视频（2.8%）高 2.9 个百分点（标准误 0.2），对数比 +0.70，40 人全部升高 |
| "不感兴趣"栏放入 10 条议题视频 | **4.0%** | 比放入 10 条非议题视频（2.8%）**高** 1.2 个百分点（标准误 0.09），对数比 +0.36，40 人全部升高；被标记的那 10 条视频本身被推荐的频率也更高（0.09% 对 0.02%） |
| 视频推荐任务：历史末尾加 20 条议题视频 | 9.6% | 比加 20 条非议题视频（2.3%）高 7.3 个百分点（标准误 0.6） |

**结论**：OneRec 对话题有很强的响应，可以作为形成实验的推荐器。但它从数据中学到的"不感兴趣"是**反向**的：放进"不感兴趣"栏的内容，同话题推荐反而增加，只是增幅约为放进"看完"栏的一半。原因有两种可能。

- *曝光选择*：用户只会对推送给他的内容点"不感兴趣"，被推送可能说明他本来就在这个话题附近。用日志检验（`ni_confounding_check.py`）：按前半段历史对议题视频的看完率把用户分为有兴趣和其他两组，后半段中有兴趣组的议题曝光占比只高 1.05–1.10 倍，而其他组对议题视频点"不感兴趣"的比例高 1.44–1.74 倍，所以一次"不感兴趣"让"有兴趣"的几率变为原来的 0.61–0.77 倍。日志本身指向正确的方向，**不支持**这种解释。
- *上下文相似*：模型把提示里出现的任何视频都当成"相关内容"的线索，而没有学会区分栏目含义。"不感兴趣"栏只在 7.2% 的训练样本中出现，模型可能没有足够信号学会反转。用同一批视频换不同栏目标题检验，结果支持这种解释（第 3.2 节）。

Wang 等（RecSys 2023）发现只用日志训练的序列模型对负反馈不敏感，因而加了显式的"不推荐"训练目标，与这里的结果一致。

### 3.2 栏目含义检验（`onerec_ni_header_probe.py`，30 名用户，精确概率）

同样 10 条议题视频放在不同标题下，计算推荐分布在 1,500 条议题候选与 1,500 条非议题候选上的议题占比（对数几率，相对不加任何视频）：

| 标题 | 对数几率变化 | 标准误 | 升高的用户比例 |
|---|---:|---:|---:|
| 用户表示不感兴趣的内容 | +0.21 | 0.03 | 97% |
| 用户不喜欢的内容 | +0.20 | 0.03 | 93% |
| 用户屏蔽的内容类型 | +0.20 | 0.03 | 97% |
| 以下是一些内容（中性） | +0.26 | 0.03 | 97% |
| 用户喜欢的内容 | +0.26 | 0.03 | 93% |
| 对照：10 条非议题视频放在"不感兴趣"下 | +0.03 | 0.02 | 57% |

三种负面标题的效果彼此几乎相同，约为中性标题的 78%。模型读出了一点栏目含义，但主要把上下文里出现的视频当作兴趣线索。这支持"上下文相似"的解释。

### 3.3 议题内的区分（`onerec_viewpoint_probe.py`，30 名用户，精确概率）

用第 5 节的 LLM 试点标签。每种属性把 A 与同形式（剧情、观点等）配比的 B 各分成"注入"和"评估"两半：把 10 条注入 A（或 B）放进"看完"栏或"不感兴趣"栏，计算评估集上 $V$（A 对 B 的对数几率）的变化。表中是"注入 A"减"注入 B"的差，正值表示推荐里 A 的几率相对更高。

| 属性 | 评估集 A / B | 放进"看完"栏 | 放进"不感兴趣"栏 | 视频推荐历史末尾加 20 条 |
|---|---:|---:|---:|---:|
| (a) 以偏概全 | 15 / 45 | **+1.13**（0.12） | **+0.63**（0.07） | +1.43（0.08） |
| (a) 按一级语义 ID 分组 | 16 / 45 | +1.05（0.06） | +0.46（0.06） | +0.36（0.09） |
| (b) 婚姻消极 | 56 / 167 | +0.34（0.05） | +0.10（0.03） | +0.25（0.07） |
| (c) 冲突叙事 | 347 / 251 | +0.65（0.05） | +0.22（0.03） | +0.61（0.07） |
| (c) 按一级语义 ID 分组 | 366 / 235 | +0.68（0.06） | +0.25（0.03） | +0.70（0.07） |
| 对照：随机假属性（与 (a) 同大小、同形式） | 15 / 45 | −0.22（0.15） | −0.14（0.11） | −0.09（0.16） |

括号内为跨用户的标准误。"按一级语义 ID 分组"让共享同一级编码的视频只出现在注入或评估一侧，排除同一故事的近似重复。

**读法**

1. **OneRec 能在议题内区分这些叙事。**随机假属性的效果接近 0，而三种属性都显著为正；排除近似重复后，(a) 和 (c) 的条件推荐效果几乎不变。所以只要用户的互动偏向某种叙事，个性化就能把它放大，形成实验有实质内容。视频推荐任务中 (a) 的效果在排除近似重复后从 1.43 降到 0.36，说明长序列中有一部分是"同一故事接着推"。
2. **"不感兴趣"在观点层面同样反向。**对以偏概全的视频点"不感兴趣"，这类叙事在推荐中的几率反而升高约 0.5–0.6（约 1.6–1.9 倍）。
3. **与 H1b 的子预测相反。**试点中立场型的 (a) 属性对比大于内容型的 (c)。可能是因为生成描述保留了"探讨'捞女'现象"这类说法（见 v4 记录），而试点的 A 集合很小、主题集中。正式实验在全部标注数据上检验，不预设方向。

对 v5 的影响：S1"不感兴趣"必须分三种实现比较（只从日志学习、显式"不推荐"目标、排序时按相似度降权），v5 第 6.4 节已写入。这个结果本身也是 RQ3 的第一个发现：在只靠日志学习的生成式推荐器里，"不感兴趣"不但不能精准起作用，连话题层面都起反作用。

## 5. LLM 标注试点（`label_pilot.py`，Qwen3-30B-A3B-Instruct-2507，GPU 1–2）

从议题候选中抽 1,800 条：600 条在出现过的视频中均匀抽样（反映"有什么"），1,200 条按曝光次数加权抽样（反映"用户看到什么"）。温度 0，全部 1,800 条都输出了合法 JSON，用时约 2 分钟。以下比例是模型判断，不是金标准。

| 量 | 均匀样本 | 曝光加权样本 |
|---|---:|---:|
| 判为与婚恋家庭相关 | 89.3% | 85.8% |
| 形式：剧情/段子 | 59.5% | 57.2% |
| 形式：个人经历 / 观点评论 / 新闻普法 | 20.2% / 9.3% / 2.2% | 22.7% / 8.3% / 1.2% |
| (a) 把个案归结为性别普遍特征（针对女性 + 针对男性） | 2.2%（2.1% + 0.2%） | 1.8%（1.3% + 0.5%） |
| (b) 对婚姻传达消极态度 | 9.0% | 6.1% |
| (c) 以婚恋或家庭冲突为核心 | 49.6% | 41.5% |
| 彩礼：批评高额彩礼 / 支持 | 3.4% / 0.2% | 1.9% / 0% |

以上比例的分母为判为相关的视频（均匀 536 条、加权 1,030 条）。

按标签汇总这些视频在日志中的反馈（曝光合并计算）：

| 标签 | 视频数 | 曝光 | 看完率 | 点赞率 | 不感兴趣率 |
|---|---:|---:|---:|---:|---:|
| (a) 针对女性 | 24 | 883 | 36.6% | 5.1% | 0.23% |
| (a) 针对男性 | 6 | 2,134 | 39.2% | 4.5% | 0.09% |
| (a) 无 | 1,536 | 233,722 | 39.9% | 4.6% | 0.09% |
| (b) 消极 | 111 | 6,721 | 41.0% | 5.4% | 0.12% |
| (b) 积极 / 中性或混合 | 723 / 732 | 124,025 / 105,993 | 37.1% / 42.9% | 4.9% / 4.3% | 0.08% / 0.09% |
| (c) 是 | 693 | 73,389 | 42.5% | 4.7% | 0.11% |
| (c) 否 | 873 | 163,350 | 38.6% | 4.6% | 0.08% |

**读法与保留意见**

1. **(a) 很少，而且标注有系统性错误。**按曝光约 1.8%。阅读模型给出的例子，有一部分是把剧情中单个反派（如"为保险金谋害丈夫的女人"）判成了"归结为性别普遍特征"。定义需要明确区分"刻画一个人物"和"推广到群体"，并由人工金标准估计误报率。
2. **(b) 与 (c) 混在一起。**被判为"对婚姻消极"的例子大多只是在讲出轨、婆媳矛盾等冲突，并没有表达"婚姻不值得"。(b) 需要改成显式立场的定义。
3. **(c) 很常见（约 41%），且看完率高 3.9 个百分点**（7.3 万对 16.3 万次曝光，差异远大于抽样误差）。
4. **H1a 的初步证据不一致。**第 2 节的关键词代理（明显标签词）点赞率更高；但 LLM 判出的 (a) 点赞率与其他视频相近。另外，三种属性在曝光加权样本中的比例都**低于**均匀样本：(a) 2.2% 对 1.8%（差 0.5 个百分点，标准误 0.8，不显著），(b) 9.0% 对 6.1%（标准误 1.4），(c) 49.6% 对 41.5%（标准误 2.6，显著）。也就是说，在出现过的视频里，这类内容平均获得的曝光反而更少。这只是"已曝光视频之间"的比较，不能代替与供给的比较，但说明"互动排序放大目标叙事"不能预设，H1a 要按双向检验登记。

**对计划的影响**：主属性用 (a)，它最接近用户关心的"观点"，也有现实分量；定义改为"把群体（而非单个人物）描绘为负面"，并用人工金标准校正。(c) 作为对照属性：它更接近"内容"，流行度高。两者放在一起形成一个梯度，可以检验命题 2 的一个推论：属性越接近描述中直接可见的内容，基于描述的表示越能区分它。(b) 改写定义后作为可选的第三属性。
