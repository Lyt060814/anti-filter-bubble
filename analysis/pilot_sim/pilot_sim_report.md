> COMP1110 小组项目 · 可行性 pilot · 2026-09-28
> 代码：`sim.py`（390 行，纯 NumPy）、`run_experiments.py`；原始输出：`results.txt` / `results.json`；图：`fig1*`–`fig4*`
> X 代码快照：`xai-org/x-algorithm`（`home-mixer/params/param.rs` 标注 last sync 2026-09-25）
> **重要声明**：本文所有数字都只在"这个玩具模型 + 这组参数"下成立。X 的 Phoenix 模型是学出来的，内部行为不公开；我们用一个简化的计数模型来代替它（下文称 Phoenix stand-in）。本 pilot 的目的是证明**可行**，并找出哪些假设决定结论，**不是**给出关于真实 X 的结论。

## 0. 一页结论

| 问题 | Pilot 答案（默认设置，200 用户，均值 ± 95% CI） |
|---|---|
| 能否在笔记本上快速跑？ | 能。200 用户 × 190 步一次约 10 s（NI 变体 C 约 32 s）；全部 70 多个配置共 **724 s**（4 核 CPU，单线程 NumPy） |
| 校准 | random 推荐器：top 类占比 0.181、20 条内不同类别数 12.0（KuaiRand 随机曝光：0.215 / 11.87）。X-like（λ=0.4）：0.241 / 9.49，比值 **1.33 / 0.79**（KuaiRand 比值 1.45 / 0.80） |
| 茧房能否形成？ | 能，但被 DPP 限制。binge 40 步后，种子话题占比从 0.03 升到 **0.45**；66% 用户曾超过 0.5。**但 s̃ 仍约 1.0**：DPP 让剩下的位置保持多样，所以按 Piao 的熵定义**不算深茧房**。关掉 DPP 后占比到 1.00，s̃ 降到 0 |
| 最便宜的逃离方式 | **S1 点"不感兴趣"**：4.3 ± 0.1 步，约 10.5 次点击（NI 作用于整个话题，变体 B）；只作用于作者（变体 A）时要 7.9 步、21.8 次点击 |
| 被动等待（S0） | 默认历史 H1（只记录动作）下，60 步内 **0%** 逃离；若"刷过的曝光也进入历史"（H2），19.7 步 |
| 主动搜索（S2，2 次/步） | 49.3 步、约 101 次搜索（H1）；H2 下 15.7 步、33 次 |
| 关注新作者（S3，10 个） | H1 下基本无效（2% 逃离）；H2 下 17.8 步，与被动等待相当 |
| 关闭个性化（S4，CAC 第 17 条 / DSA 第 38 条） | 1.9 步立即"逃离"，但**效用只剩 0.33**，而且一回到个性化推荐就**完全复发**（R = 0.56，与 S0 相同）：历史记忆没有被改变 |
| 组合（S5 = S1+S2+S3） | 4.0 步、约 25 次操作；复发 R ≈ 0 |
| 复发 | 用户逃离后恢复正常行为，且对种子话题保留 20% 残余兴趣（h=0.2）。H1 下 NI 类策略几乎不复发（NI 记录留在 FIFO 里继续压制）。H2 下 60 步内回升到 R≈0.13–0.27 |

**最重要的方法学发现**：结论主要由三个**X 代码里看不到**的假设决定。它们应当成为正式项目的核心实验变量：
1. 用户的"跳过/只看不点"是否进入行为序列（H1 vs H2）。它决定被动等待是否有效（0% vs 100%）。
2. 同一话题帖子的 embedding 相似度，它决定 DPP 的多样化力度（峰值 0.20–0.77）。
3. NI 的泛化范围（作者 / 话题 / 语义）。它决定 NI 成本相差约 2 倍。

## 1. 模型规格（对应课程 Simulation/Modelling rubric：变量、状态、规则、时间步、输出）

### 1.1 时间步与阶段
- **1 步 = 用户刷新一次 For You，看到 10 条帖子（slate）**。60 步 ≈ 600 条帖子。
- 每个用户依次经历四个阶段（默认步数）：

| 阶段 | 步数 | 用户行为 |
|---|---|---|
| P0 正常使用 | T0 = 30 | 按真实偏好互动 |
| P1 binge | T1 = 40 | 只和种子话题互动；每步主动搜索种子话题 5 次；每步以 0.2 的概率关注一位刚互动过的种子作者 |
| P2 逃离 | T2 = 60 | 停止与种子话题互动，其他话题按真实偏好互动，并执行策略 S0–S5 |
| P3 复发检验 | T3 = 60 | 停止策略，恢复正常；偏好中残留种子兴趣 p′ ∝ p + 0.2·onehot(seed) |

- 种子话题是用户真实偏好排第 4–20 的某个话题，即"兔子洞"，而不是本来的主兴趣。其真实偏好平均只有 0.027。

### 1.2 世界（变量）

| 变量 | 含义 | 取值 / 生成方式 | 来源 |
|---|---|---|---|
| K | 话题数 | 20 | Chaney+2018、Piao+2023 都用约 20 个 |
| 话题中心 c_k ∈ R^32 | 话题 embedding | 分 5 组相关话题：c = unit(0.6·组向量 + 0.8·随机)，组内余弦约 0.3 | [假设] 模拟"相关话题" |
| 作者 | 400 位，每话题 20 位 | 各有一个主话题和一个风格向量 | world.py |
| 帖子 | 每步为每个用户**新生成** 150 个候选 | 话题、作者、embedding = unit(c + 0.35·style + 0.5·noise)，质量 q ~ LogNormal(0, 0.7) | world.py:417-429（原噪声 0.15，见 §4） |
| g | 全局话题热度 | Dir(3) | [假设] 调到使 random 推荐与 KuaiRand 随机曝光相近 |
| p_u | 用户真实偏好 | Dir(10·g) | Chaney+2018；平均归一化熵 0.75（KuaiRec 曝光熵约 0.76） |

### 1.3 状态（每个用户）
- **行为历史 H_u**：FIFO 队列，保留最近 M = 200 个事件，类型为 ENG（点赞/停留、搜索点击、关注）、NI 或 SKIP（仅 H2）。开局用 M 个按 p_u 抽样的 ENG 事件预热，代表老用户。对应 X 的 user action sequence（param.rs:770-781，长度 1024）。
- **关注集合 F_u**：初始 15 位作者（按 p_u 抽话题）。binge 和 S3 期间会增加。
- 推荐器**没有**其他用户状态。这与 X 一致："the user is represented by what they interacted with"（phoenix/README.md:101-108）。

### 1.4 每步规则
1. **召回 150 个候选**（缩小版的 X 三路来源）：
   - 30 个 in-network：来自关注作者，80% 是作者主话题（对应 Thunder）；
   - 70 个 OON 召回：话题按历史亲和度 rel_k 抽样（对应 Phoenix retrieval / SimClusters，"越像历史越多"）；
   - 50 个全局新帖：话题按 g 抽样。
2. **预测**（Phoenix stand-in，[假设]）：
   - 话题亲和度：aff_k = (n_eng,k + 1)/(Σn_eng + K)；rel_k = (K·aff_k)^λ，λ = 0.4 由校准得到。
   - 预测互动概率：p̂_eng = 1 − exp(−0.1 · rel_k · (1 + 0.5·min(n_eng,author,3)/3) · q · e^{0.1ε})。
   - 预测不感兴趣概率：p̂_NI = (n_NI + 0.002·10)/(n_NI + n_eng + 10)，即该用户对"同一对象"的反应中 NI 所占比例（平滑）。"同一对象"按 NI 变体定义：
     - **A** = 同一作者（对应 X 的 "Show fewer from @author"）；
     - **B** = 同一话题（"Not interested in topic"）；
     - **C** = embedding 相似的帖子：按 cos > 0.2 软计数。
3. **X 打分**：
   - S_raw = 2.83·p̂_eng + 4·0.02·p̂_eng·[OON] − 43.2·p̂_NI − 0.02·(1 − p̂_eng)。
   - 负分压缩：S_raw ≥ 0 时 S = S_raw + 0.001；否则 S = (S_raw + 367.22)/410.56 · 0.001（scoring.rs:121-130）。
   - 2.83 是把 favorite 0.5、reply 5、retweet 1、quote 5、share 2、dwell 0.05 按 world.py 的基础比例折合到一个 p̂_eng 上的结果。
4. **作者多样性**：S ×= 0.75·0.5^k + 0.25，k 为候选池中同作者且分数更高的帖子数（scoring.rs:143-164，vm-ranker/params.rs:139-156）。
5. **OON 折扣**：未关注作者的帖子 ×0.75（vm-ranker/params.rs:175-180）。
6. **DPP**：
   - 在全部 150 个候选上（= DppMaxSelectedRank 150）做 greedy MAP；q = exp(α·s/s_max)，α = θ/(2(1−θ))，θ = 0.65；L_ij = q_i q_j cos(e_i, e_j)（dpp.rs:92-314）。
   - 选出 14 个，再按原分数取前 10 个展示。这对应 X "DPP 选 50 → 展示 35" 的比例。DPP 只是过滤器，保留原分数顺序（dpp.rs:154-171）。
7. **用户反应**（真实模型，推荐器看不到）：
   - 位置 r 的帖子被互动的概率为 r^−0.8 · min(1, 0.35·K·p_u[c]·q)。位置偏差来自 Chaney+2018。
   - 互动写入 H_u；再按阶段或策略执行额外动作（搜索、NI、关注）；H2 下未互动的曝光也作为 SKIP 写入 H_u。

### 1.5 逃离策略（P2）

| 策略 | 做法 | 计入的"用户操作" |
|---|---|---|
| S0 被动 | 不看种子，其余正常 | 0 |
| S1 NI | 对每条展示出来的种子帖点"不感兴趣" | NI 点击数 |
| S2 搜索 | 每步搜索并互动 2 次非种子话题（按 p_u） | 搜索次数 |
| S3 关注 | 前 10 步每步关注 1 位非种子话题的新作者 | 关注数 |
| S4 关闭个性化 | 整个 P2 使用随机/非个性化推荐流，但行为仍写入历史 | 1（开关） |
| S5 组合 | S1 + S2 + S3 | 以上之和 |

### 1.6 输出（指标）
- 每步基于最近 3 步（30 条帖子）滚动窗口计算：
  - **种子占比**；
  - **归一化话题熵** H/ln K；
  - **s̃ = H / s\***，s\* 为从 p_u 抽 30 条时熵的期望，即用户的"内在多样性"（Piao+2023；s̃ ≥ 1 多样，0.5–1 部分茧房，< 0.5 深茧房）；
  - in-network 占比；
  - 真实效用 Σ_r r^−0.8·min(1, 0.35·K·p_u[c]·q)。
- 派生指标：
  - time-to-cocoon：P1 中种子占比首次 > 0.5 的步数；
  - **逃离步数**：P2 中种子占比首次 < 基线 + 0.1，60 步内未达到按 60 截尾；
  - 逃离操作数；
  - 另一种逃离判据：熵回到基线 0.9 倍的步数（`esc_H`，在 results.json 中）；
  - **复发比 R** = (P3 末 10 步种子占比 − 基线)/(峰值 − 基线)；
  - 复发时间：P3 中回到"一半峰值"的步数；
  - 效用比 = P2 平均效用 / P0 平均效用。
- 只统计"被 binge 真正推动"的用户，即峰值 − 基线 > 0.2。默认设置下为 100%。

## 3. 校准（Phase 0，20 条曝光为一块，与 KuaiRand 分析口径相同）

| 推荐器 | top 类占比 | 20 条内不同类别数 | 比值（相对 random） |
|---|---|---|---|
| KuaiRand 随机曝光（目标） | 0.215 | 11.87 | — |
| KuaiRand 算法曝光（目标） | 0.312 | 9.49 | **1.45 / 0.80** |
| 本模型 random | 0.181 | 12.00 | — |
| X-like λ=0.25 | 0.200 | 10.70 | 1.11 / 0.89 |
| **X-like λ=0.4（选用）** | **0.241** | **9.49** | **1.33 / 0.79** |
| X-like λ=0.5 | 0.270 | 8.88 | 1.49 / 0.74 |
| X-like λ=1.0 | 0.490 | 5.83 | 2.71 / 0.49 |
| X 去掉 DPP（λ=0.5） | 0.534 | 4.73 | 2.95 / 0.39 |
| 纯 greedy（λ=0.5） | 0.565 | 4.62 | 3.12 / 0.38 |

解读：
- 按两个比值的相对误差之和选 λ = 0.4。"不同类别数"比值几乎完全吻合；top 占比比值略低于 KuaiRand（1.33 vs 1.45）。
- **没有 DPP 时，任何 λ ≥ 0.5 都会比 KuaiRand 集中得多**，大约 3 倍。换句话说，在我们的模型里，DPP 是让"正常使用"下的集中度落在真实范围内的主要机制。
- 这只是**形状/量级校准**：KuaiRand 是 2022 年的快手，有 43 个标签，不是 X。

## 4. 主要结果

### 4.1 茧房形成（P1）
- 默认 X-like 下，种子占比从 0.03 升到 0.45（峰值为 P1 最后 5 步均值）。66% 用户曾超过 0.5；time-to-cocoon 均值 35.3 步（未超过者按 40 截尾计入）。
- **s̃ 从 1.08 只降到 1.00**。DPP 与作者多样性让剩下约 55% 的位置分散在其他话题上，所以按"种子占比"看形成了茧房，按"熵"看没有。**这两个茧房定义在 X-like 下会分离**，正式报告必须同时报告两者。
- 消融（`fig3_ablation.png`，峰值种子占比 / s̃）：

| 设置 | 峰值种子占比 | s̃ | time-to-cocoon |
|---|---|---|---|
| X 完整 | 0.45 | 1.00 | — |
| 无作者多样性 | 0.49 | 0.95 | — |
| 无 OON 折扣 | 0.49 | 0.95 | — |
| **无 DPP** | **1.00** | **0.00** | 19.5 步 |
| greedy | 1.00 | 0.00 | 17.7 步 |
| θ = 0.5 | 0.21 | — | — |
| θ = 0.8 | 0.92 | 0.18 | — |

  - **DPP 是最强的"刹车"**；作者多样性和 OON 的作用都只有约 0.04。
  - OON 折扣本身是收窄因素。我们的推测是：在这个设定里种子作者大多未被关注，所以 ×0.75 反而压低了种子帖（未单独验证）。
- 对不可观测参数高度敏感：
  - 同话题余弦 0.88（world.py 原值）时，峰值 0.20；
  - 余弦 0.57 时，峰值 0.77，s̃ 0.48，进入深茧房；
  - λ = 1.0 时，峰值 0.98；
  - M = 50 / 400 时，峰值 0.35 / 0.30。M = 400 较低是因为 binge 在更长的历史中被稀释；M = 50 也低于 M = 200，这一非单调现象**尚未解释**，正式项目需要检查。

### 4.2 逃离成本（P2，`fig1_seed_share_curves.png`、`fig2_escape_cost.png`）

| 策略 | H1 步数 | H1 操作数 | H1 逃离率 | H2 步数 | H2 操作数 | P2 效用比（H1） |
|---|---|---|---|---|---|---|
| S0 被动 | 60（截尾） | 0 | **0%** | 19.7 ± 0.2 | 0 | 0.55 |
| S1-A NI→作者 | 7.9 ± 0.2 | 21.8 | 100% | 7.6 | 19.4 | 0.85 |
| **S1-B NI→话题** | **4.3 ± 0.1** | **10.5** | 100% | 2.9 | 5.4 | 0.90 |
| S1-C NI→语义 | 4.5 ± 0.1 | 11.2 | 100% | 3.0 | 5.8 | 0.84 |
| S2 搜索 2/步 | 49.3 ± 0.8 | 100.6 | 100% | 15.7 | 33.4 | 0.72 |
| S3 关注 10 人 | 59.8（截尾） | 10 | 2% | 17.8 | 10 | 0.58 |
| S4 关闭个性化 | 1.9 ± 0.1 | 1 | 100% | 1.8 | 1 | **0.33** |
| S5-B 组合 | 4.0 ± 0.1 | 24.8 | 100% | 2.8 | 16.6 | 0.95 |

（S5-A 7.6 步 / 46.5 次，S5-C 4.3 / 26.2。三个随机种子复现，逃离步数差异 ≤ 0.8 步，见 results.txt。）

要点：
1. **"不感兴趣"是最划算的主动操作**：约 10 次点击、4 步（约 40 条帖子）。
   - 它有效的原因在 X 的权重结构：−43.2 的 NI 权重约为全部正向权重（2.83）的 15 倍，所以 p̂_NI 只要升到约 0.06，就能抵消一个满分的正向预测。
   - 对照：没有 NI head 的 greedy 推荐器下，同样的 S1 要 23.7 步（`fig3`）。
2. **NI 的泛化范围决定成本**：只作用于作者（A）的成本约为作用于话题（B）的 2 倍（21.8 vs 10.5 次点击），因为每个种子话题有 20 位作者，要逐个"拉黑"。语义泛化（C）与 B 接近，因为同话题余弦高，而相关话题的溢出很小。
3. **被动等待是否有效，完全取决于跳过是否进入历史**：
   - H1 下历史只在用户"做事"时更新。用户不再互动后，旧的种子互动永远不会被挤出 FIFO，于是 60 步后占比仍有 0.36。
   - H2 下每次刷新都挤出 10 个旧事件，约 20 步（200/10）逃离。
4. **搜索是昂贵的**（H1 约 100 次），因为它要一条条"稀释"约 100 个种子事件。**关注新作者在 H1 下几乎无效**：它只改变 in-network 候选（30/150），而种子帖仍占据召回和高分。
5. **关闭个性化立刻见效，但代价是效用降到 33%，而且不留记忆**。

### 4.3 复发（P3）
- **S4 关闭个性化在 H1 下完全复发**：回到个性化推荐后，种子占比升到 0.26（R = 0.56），与从未逃离的 S0 相同（0.27）。
  - 原因：在非个性化期间，只有约 20 个新的互动写入 200 长度的历史，推荐器的"记忆"基本没变。
  - **政策含义**：监管要求的"关闭个性化"开关只是暂停，不是重置。若要真正"破茧"，需要配合标签删除或历史重置。这可以作为项目的讨论点。
- **NI 类策略（S1/S5）几乎不复发**（H1 下 R ≈ 0）：NI 事件留在 FIFO 里，继续压低种子的预测分。
  - 这种保护会在约 M 个新行为后过期：H2 下复发 R ≈ 0.21，约 16% 用户回到一半峰值。
  - 残留兴趣 h = 0 时，所有策略的 R ≈ 0。所以复发主要来自用户的残留兴趣与历史记忆的**交互**。
- S2 搜索在 H1 下同样低复发（R = 0.01），因为它把历史彻底换成了非种子事件。
- M 的影响：M = 50 逃离快（S1 2.4 步，S2 13.1 步），但复发多（R 0.23–0.27）。M = 400 让 S2 几乎无效（4% 逃离），但 NI 的保护更长久。**短记忆 = 容易进、容易出、容易复发。**

## 5. 运行时间与规模
- 一次运行 = 200 用户 × 190 步 × 150 候选：约 10 s。NI 变体 C 需要 (U × 150 × M) 的相似度矩阵，约 32 s。100 用户约 5.5 s。
- `run_experiments.py` 共约 70 次运行：校准 8 次、主实验 20 次、复现 12 次、消融 30 次，总计 **724 s**（约 12 分钟）。
- 规模可以加到 1000 用户（线性增长），也可以加到 M = 1024（主要是内存 U × M × 32 float32，1000 用户约 130 MB，可接受）。

## 6. 局限（诚实声明）
1. **Phoenix stand-in 是最弱的一环**：p̂_eng 和 p̂_NI 的函数形式都是我们编的。真实模型可能从单次 NI 泛化得更远或更近，也可能根本看不到 NI（序列类型 DENSE_WITH_LONG_DWELL 存疑）。
2. **几个决定性参数无法从代码或数据得到**：跳过是否入历史、同话题 embedding 相似度、NI 泛化方式、binge 强度。我们用"两端都跑"的方式处理，而不是假装知道。
3. **DPP 在生产环境是否启用无法确认**（`--dpp-enabled` 的 CLI 默认值为 false）。无 DPP 时结论明显不同：深茧房，被动与搜索几乎都逃不出，NI 仍然有效。
4. 未建模：
   - 互关回复加成（+15）、冷启动提升、mute/block 与关键词硬过滤、帖子 48 h 时效、Who-to-Follow；
   - 真实的时间刻度（1 步 ≠ 固定时长）；
   - 用户的偏好漂移（P1 的 binge 是"表演"出来的行为，真实偏好没有改变）。
5. 只在一个 20 话题的合成世界中校准，而且只用了两个聚合比值；没有用 KuaiRec 的真实用户偏好向量（可选项，未做）。
6. "逃离"的判据（基线 + 0.1）和滚动窗口（30 条，带约 1–2 步滞后）是约定；`esc_H`（熵判据）已输出，但尚未纳入分析。
7. 用户完全执行策略，例如对每一条种子帖都点 NI。真实用户的依从率与操作疲劳没有建模。

## 7. 对正式项目的建议设计
1. **保留这个架构**：纯 NumPy、按用户批处理、X 的打分/多样性/DPP 逐行对照源码。它已经足够快，一年级同学能读懂并扩展。
2. **把三个"不可见假设"升级为主实验因子**（全因子，每格 ≥ 200 用户 × 3 随机种子）：
   - 历史类型 H1 / H2；
   - NI 泛化 A / B / C；
   - DPP 开 / 关（θ ∈ {0.5, 0.65, 0.8}）。
   - 其余（M、λ、embedding 噪声）作为一维敏感性分析。
3. **两个茧房定义并列报告**（种子占比与 s̃），并解释它们在有 DPP 时为何分离。
4. **加两个策略**：
   - S6 "重置/删除兴趣标签"（清空或截断 H_u），用来检验"关闭个性化只是暂停"这一发现；
   - S7 "部分依从 NI"（每条种子帖只以概率 ρ ∈ {0.2, 0.5} 点击），得到更真实的成本曲线。
5. **做一次 embedding 相似度的实测锚定**：用任意开源文本 embedding 模型，在 KuaiRec 的 caption（`kuairec_caption_category.csv`）上计算同类 / 异类余弦，替换当前的 emb_noise 假设。这是最能收窄不确定性的一步，约 1 小时。
6. **与 DETECT 部分对接**：P1 中 time-to-cocoon 的曲线，以及种子占比与 s̃ 的分离，可以直接作为"用户能多早察觉"的仿真对照。
7. 若时间允许，用 KuaiRec 的用户-类别观看比例替换 Dir(10·g) 偏好，并用 KuaiRand 的 `is_hate` 后续曝光变化（`analysis/deep_A_kuairand_kuairec/hate_followup.*`）对 NI 的效果做一次粗校准。
