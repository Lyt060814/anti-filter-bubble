# D3 双模型核查：婆媳、后妈和单个反派是 Qwen 的主要误报（v0 初稿，2026-11-07，Zhao Dingcheng）

**结论**：用 v0 提示词时，Qwen3-30B 判为"群体标签"的视频是参照模型 DeepSeek V4 Pro 的近 3 倍（4.0% 对 1.4%），两者重合的只有 2 条。以 DeepSeek 为参照，Qwen 的查准率是 10%，查全率是 29%，Cohen's kappa 为 0.13。也就是说，**v0 下 Qwen 给出的群体标签不能直接使用**。误报大多是把家庭角色（婆婆、后妈、父亲）或剧情里的单个人物当成了整个性别群体，这正是 D1、D2 收紧定义要解决的问题。v1 的结果出来后，本文更新数字，并补上第 5 节"v0 → v1 的变化"。

脚本：[agreement.py](agreement.py)。结果：[agreement_v0.json](results/agreement_v0.json)（全部数字与区间）、[混淆矩阵](results/agreement_v0_confusion.csv)、[分歧清单](results/agreement_v0_disagreements.csv)（只含 pid、标签和类别）、[meta](results/agreement_v0.meta.json)。重跑：

```bash
cd analysis/v6_annotation && python -I agreement.py ../v6/results/dual_v0_labels.csv
```

证据类型：**实测**，但这是"一个模型对照另一个更强的模型"，不是人工金标准（见第 4 节）。

## 1. 数据

- 来自 [analysis/v6/results/dual_v0_labels.csv](../v6/results/dual_v0_labels.csv)：按曝光次数加权，从婚恋家庭关键词候选中抽了 500 条视频（种子 23），提示词 v0。
- 三个模型：Qwen3-30B-A3B-Instruct-2507（本地，全量标注要用的模型）、DeepSeek V4 Pro（API，主参照，500 条全标）、GPT-6.1 Sol（API，第二参照，只标了前 150 条）。
- **缺失**：Qwen 有 2 条输出不合法，记为缺失，不算进二者的比较；DeepSeek 没有缺失；GPT 标的 150 条也没有缺失。两条缺失都不在 DeepSeek 判为群体标签的视频里，因此不影响查全率。
- **加权**：样本按曝光加权抽取，所以按视频数算的比例，估计的就是"议题曝光中的比例"，分析中不再额外加权。
- **阳性**：`group_label` 为"针对女性"或"针对男性"。"无法判断"在二分类指标里算阴性；v0 中三个模型都没有输出"无法判断"。

## 2. 群体标签：Qwen 对照 DeepSeek

**混淆矩阵**（498 条两者都有结果的视频；行是 Qwen，列是 DeepSeek）：

| Qwen \ DeepSeek | 针对女性 | 针对男性 | 无 | 合计 |
|---|---:|---:|---:|---:|
| 针对女性 | 1 | 0 | 10 | 11 |
| 针对男性 | 0 | 1 | 8 | 9 |
| 无 | 4 | 1 | 473 | 478 |
| 合计 | 5 | 2 | 491 | 498 |

**指标**（比例用 Wilson 95% 区间，kappa 用 2,000 次自助法）：

| 指标 | 值 | 95% 区间 |
|---|---:|---|
| Qwen 判为群体标签的比例 | 4.0%（20 条） | — |
| DeepSeek 判为群体标签的比例 | 1.4%（7 条） | 0.7%–2.9% |
| Qwen 查准率（判为标签的里面，参照也同意的比例） | 10%（2/20） | 2.8%–30% |
| Qwen 查全率（参照判为标签的里面，Qwen 也判出的比例） | 29%（2/7） | 8%–64% |
| Qwen 误报率（参照判为"无"的里面，Qwen 判为标签的比例） | 3.7%（18/491） | 2.3%–5.7% |
| 原始一致率 | 95.4% | — |
| Cohen's kappa（是否为群体标签） | 0.13 | −0.02–0.32 |
| Cohen's kappa（四类，区分方向） | 0.13 | — |
| Cohen's kappa（叙事类型，五类） | 0.23 | 0.07–0.39 |
| Cohen's kappa（是否婚恋家庭相关） | 0.70 | — |

读法：

1. **一致率高，但没有意义。**群体标签很少见，两个模型都说"无"就能得到 95% 的一致率；扣掉这种偶然一致之后，kappa 只有 0.13，接近随机。
2. **Qwen 系统性地多判。**20 条里有 18 条参照不同意；而参照判出的 7 条，Qwen 漏了 5 条。两者重合的 2 条，方向也一致（一条针对女性，一条针对男性）。
3. **"婚恋家庭相关"的判断比较可靠**（kappa 0.70）：分歧主要在一个方向：Qwen 判为相关、DeepSeek 判为不相关的有 39 条，反过来只有 5 条。
4. **校正后的比例。**用 Rogan–Gladen 方法、按上表的查全率和误报率校正 Qwen 的 4.0%，得到 1.4%（95% 区间 0.6%–2.6%）。在同一个样本上，校正值本来就会回到参照的比例，所以它本身不是新信息；它的用处是：如果 L3 用**同一个提示词**做全量标注，可以用这组查全率和误报率来校正。不过查全率的区间太宽，按 v0 的误差校正，结果很不稳定。全量标注应该用 v1，并用 v1 的核查结果来校正。
5. **和 v5 试点一致。**DeepSeek 估计约 1.4% 的议题曝光含性别群体标签，与 v5 试点中 Qwen 用另一份提示词得到的 1.8% 接近。

## 3. 分歧的类型

把 Qwen 与 DeepSeek 不一致的 23 条视频，按两个模型给出的依据归类。归类用的是脚本里的关键词规则（`CATEGORIES`），只是为了整理；我逐条读过依据，规则的归类与依据的意思相符。下面的描述都是对类型的概括，不引用视频描述。

| 类型 | 条数 | 典型情形 |
|---|---:|---|
| 家庭角色被当作性别群体 | 7 | 婆媳冲突里的婆婆、剧情里的后妈、索要彩礼的父亲，被 Qwen 当作"女性"或"男性"整体的特征；参照认为这只是具体人物 |
| 个案被说成推广 | 5 | 剧情中单个丈夫或妻子的恶行（出轨、家暴、自私），Qwen 的依据写"将个别行为泛化为群体特征"，但描述里没有推广的说法 |
| 调侃或幽默被当作贬低 | 3 | 动物"怕老婆"的段子、对小孩的玩笑称呼、调侃厨艺的家庭日常 |
| 参照判为其他叙事类型 | 2 | 参照认为是"焦虑渲染"（劝学时拿婚嫁后果吓人）或"二元对立"（婆媳对立），Qwen 归成了群体标签 |
| 其他 | 1 | 把汽车拟人化为"男友特质"，Qwen 判为给男性贴标签 |
| Qwen 漏判 | 5 | 参照判为群体标签、Qwen 判为"无"：文案用贬义词形容某类女生；多个女性角色被总结为"现代女性"的普遍特征；以某件事作为评判男人好坏的标准 |

规律：

- **Qwen 的误报几乎都出在"对象是谁"这一步。**18 条误报中，有 12 条是家庭角色或单个人物被当成了群体。Qwen 的依据常常写"将个别……泛化为……群体特征"，也就是说它自己承认这是个案，却仍然判为推广。v1 提示词要求先写"对象：个人／群体"，再逐条回答四个问题，就是针对这一点。
- **剧情类最容易出错**：误报中有 10 条是剧情或段子。
- **漏判要看措辞。**参照判出、Qwen 漏掉的视频，通常有一个明确的推广信号，比如贬义称呼或"现代女性都……"这样的总结。v1 把这类信号列成了"有没有推广"的判断条件。

## 4. 局限

- **参照本身也是模型。**DeepSeek 不是人工金标准，上面的"查准率""查全率"实际上是"与一个更强的模型一致的程度"。如果两个模型犯同样的错误（例如都忽略了画面里才有的信息），核查发现不了。
- **第二参照太少。**GPT-6.1 Sol 只标了 150 条，其中只有 1 条判为群体标签。DeepSeek 与 GPT 的 kappa 为 0.49，但区间是 0–1，不能用来评估参照本身可不可靠。两个前沿模型在 150 条上的原始一致率为 98.7%（DeepSeek 多判了 2 条）。
- **阳性太少。**参照只判出 7 条群体标签，所以查全率的区间很宽（8%–64%）。如果要更准地估计查全率，需要先用关键词或模型多筛一些候选，再在候选上核查。
- **只能看描述。**所有模型看到的都是模型生成的文字描述，不是视频本身。描述里没写出来的语气、画面字幕和评论区内容，都不在判断范围内。
- **叙事类型的一致率也低**（kappa 0.23）。v0 下两个模型对"有没有对立叙事、是哪一类"分歧很大，这也是 v1 加上判断顺序和排除规则的原因。

## 6. 给其他部分的提示

- **L3 全量标注**：不要用 v0 的 Qwen 群体标签，等 v1 的核查结果。
- **L4 OneRec 实测**：v5 的"注入以偏概全视频后几率约升到 3 倍"用的是 v5 试点的 Qwen 标签。如果那批标签的误报率和这里相近，被注入的视频里有相当一部分其实是"单个反派"，复现时应该改用 v1 的标签。
- **自下而上抽样的 63%**：[v6 抽样](../v6/README.md)中，"性别与婚恋"大类里有 63% 被判为"表达对立叙事"；而这里 DeepSeek 只把 3.8% 的婚恋候选视频判为有对立叙事，Qwen 是 5.0%。两者的样本（大类与关键词候选）和提示词不同，不能直接比较，但差距很大，说明"是否对立"的判断非常依赖提示词。第 4 节报告 RQ1 的比例时，需要用同一份提示词重新估计。
