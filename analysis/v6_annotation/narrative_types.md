# D1 叙事类型定义（v2，2026-11-07，Zhao Dingcheng）

本文定义 v6 使用的四类"对立叙事"：唯一正确、二元对立、焦虑渲染、群体标签。D2 的标注提示词（[prompt.md](prompt.md)）由这份定义改写而来；两者不一致时以本文为准，并同步修改提示词。

例子全部是我们自己编写的典型情形，不来自任何视频描述原文。

**v2 修订**（issue #10，依据见 [agreement.md](agreement.md) 第 5 节）：对象默认是个人，角色称呼不算群体；泛指一类人的贬义总结也算推广；视频自己说出的话默认认同；按具体恶行定义的人不算性别群体；劝告、评判和结论算作表达立场。下文相应位置标注了"v2"。

## 0. 共同规则

1. **标的是视频认同的叙事，不是视频里出现过的说法。**视频转述、反驳或嘲讽某种说法（"别再说女人都物质了"），不算该叙事。剧情里某个角色说了一句偏激的话，要看整条视频是在肯定它（结尾印证、配乐和字幕站在这边），还是把它当作被纠正的错误。看不出来时，标"无法判断"，不要猜。**v2**：视频**自己**的标题、字幕、旁白或博主原话说出来的，默认视频认同，除非视频明确反驳或嘲讽它。
2. **看内容，不看体裁。**剧情、段子、个人经历、观点评论、新闻都可能含对立叙事，也都可能不含。体裁单独记在 `genre` 字段里。
3. **只根据描述判断。**我们拿到的是模型根据视频生成的文字描述，不是视频本身。描述者自己加的概括（如"反映了当代婚恋现象"）不等于视频在推广；要看描述里视频**本身**说了什么、演了什么；描述中转述的视频字幕、台词和旁白，属于视频本身。
4. **只记一类。**一条视频符合多类时，按以下顺序取第一个符合的：**群体标签 → 唯一正确 → 二元对立 → 焦虑渲染**。群体标签放第一，因为它是案例研究的目标属性，不能被其他类型盖掉；唯一正确比二元对立多下了一个"哪边对"的结论，更具体，所以排在前面；焦虑渲染讲的是手法，最后考虑。
5. **都不符合就是"无"。**中性记录、介绍、单纯的情感故事、娱乐内容都标"无"。有冲突不等于有对立叙事：讲出轨、婆媳吵架的视频大多数是"无"（v5 试点中，冲突类内容约占议题曝光的 41%，但大部分没有表达立场）。**v2**：反过来，博主直接给出劝告、评判或结论（"女生一定要……""千万别……"），就是在表达立场，按四类判断。
6. **营销内容排除。**商品、课程、"赚钱游戏"、婚恋中介等的推销话术，即使用了制造焦虑的说法，也标"无"，原因写"营销"。这是自下而上抽样中消费类"焦虑渲染"偏高的原因（见 [analysis/v6](../v6/README.md)）。

## 1. 群体标签（目标属性）

**定义**：把一个社会群体（性别、地域、年龄、职业、出身等）**整体**描绘为负面；或者把一个个案说成这个群体的普遍特征。

**判断步骤**（依次回答，任何一步答"否"就是"无"）：

1. **批评对象是谁？**是一个具体人物（剧中某个丈夫、博主的前任），还是一类人（"女人""90 后男生""某地的人"）？**v2**：默认是具体人物。婆婆、丈夫、继母、前任、相亲对象这样的角色称呼都指具体人物；只有描述里出现明确指称一类人的说法或贬义称号，才算一类人。按具体恶行定义的人（家暴者、出轨的人、骗子）也算具体人物，除非视频把这种恶行说成某一性别的普遍特征（"男人都会家暴"）。
2. **有没有推广？**以下三种情况算推广：
   - 全称或近似全称的说法："都""没一个""十个有九个""就是这样的"；
   - 用贬义的群体称号解释某个人的行为："这就是典型的凤凰男""一看就是捞女"，其他这类称号还有妈宝男、扶弟魔、普信男等；
   - 由个案得出群体结论："所以说，娶某地的姑娘一定要小心"；
   - **v2**：泛指一类人的贬义总结，不要求出现"都"："现在的女生就是……""有些男人就是……"。
3. **是负面特征吗？**指人品、能力、动机上的负面属性，比如物质、靠不住、心机重、懒、不讲理。只说某个群体"很难""很累""压力大"，是在诉苦，不是贴负面标签；但"男人太难了，因为女人都只看钱"是针对女性的标签。
4. **视频认同吗？**按共同规则 1 判断。

**正例**：

- 一位博主讲完自己被前女友分手的经历，最后总结"现在的女生谈恋爱都是在挑提款机"。个案推广到了群体，针对女性。
- 一个短剧里，男主角的母亲干涉小两口过日子，旁白和字幕说"嫁给凤凰男就是嫁给他全家"。贬义群体称号加上群体结论，针对男性。

**容易误判的反例**（都应标"无"）：

- 剧情里一个妻子为了保险金谋害丈夫，结尾她被抓了。这是**单个反派**，视频没有说"女人都会这样"。v5 试点的误报主要出在这一类。
- 一条视频列出网上流行的"男人都靠不住"等说法，然后逐条反驳。视频转述了标签，但立场是反对它。
- （v2）丈夫偷吃妻子藏的零食被发现，两人互相打趣。这是夫妻搞笑互动，没有贬低任何一方，更没有推广到性别。v1 提示词下 Qwen 把大量这类视频判成了群体标签。
- （v2）博主讲述一起家暴案件，批评施暴的丈夫。批评的是按恶行定义的具体的人，没有说男性都会家暴。

**边界情形**：

- **调侃**：把负面特征归给整个群体，即使语气是开玩笑，也算（如"女人都爱翻男朋友手机，这是天性"）。拿自己的群体自嘲而又没有负面归因的，比如"我们男人在家就是没地位"，不算。
- **两个性别都被贴了标签**：选更突出的一方，在依据里写明另一方也被贴了标签。
- **非性别的群体**（地域、年龄等）：`narrative_type` 记"群体标签"，`group_label` 记"无"，因为后者只区分性别方向。依据里写明对象是什么群体。

## 2. 唯一正确

**定义**：把一种选择或做法说成唯一正当的路，同时贬低或否定其他选择。

**判断要点**：要同时有两样东西，一是对某个选项的肯定（"只有……才……""女人最终的归宿是……"），二是对其他选项的否定或嘲讽。只是推荐某种做法，不贬低别的，不算。

**正例**：

- "不结婚的女人老了都没人管，结婚生子才是正道"：肯定一种选择，否定另一种。
- "男人不买房就别谈恋爱，谈了也是耽误别人"：把买房说成恋爱的唯一前提。

**容易误判的反例**：

- 博主分享自己婚后的幸福生活，说"我觉得结婚挺好的"。这是个人经验，没有否定别的选择。
- 普法视频讲婚前财产怎样约定才有效。这是信息，不是价值判断。

## 3. 二元对立

**定义**：把一个问题说成只有两个对立的阵营或选项，非此即彼，排除中间状态和其他可能。

**判断要点**：看有没有"要么 A 要么 B"的框架，或者把两个群体、两种立场说成天然对立。如果框架里还明确宣布了哪一边对、并贬低另一边，按优先顺序记"唯一正确"；如果某一边被贴上群体性的负面标签，记"群体标签"。

**正例**：

- "婚姻里只有两种人，掌控的和被掌控的，你不立规矩就会被欺负"：把关系简化成两极。
- "彩礼这件事，站男方就是不尊重女方，站女方就是贪钱，没有中间立场"：排除了中间位置。

**容易误判的反例**：

- 一对夫妻在节目里对家务分工意见不同，主持人请双方各说理由。这是两种意见，不是非此即彼的框架。
- "支持还是反对高额彩礼？评论区告诉我"。只是在征集观点，视频本身没有立场。

## 4. 焦虑渲染

**定义**：用恐惧、紧迫感或羞耻感推动一个观点或选择，而不是用理由或信息说服。

**判断要点**：

- 典型手法：年龄或时间的倒计时（"过了 28 岁就没人要了"）；夸大风险（"不留一手，离婚时你一分钱都拿不到"）；拿"别人都已经……"制造落后感。
- 要有一个被推动的观点或选择。只是讲一件悲伤或可怕的事，没有借此推动什么，不算。
- 营销话术不算（共同规则 6）。

**正例**：

- "30 岁还不结婚的女生，最后只能挑别人剩下的"：用年龄恐惧推动"尽早结婚"。
- "现在不存钱，以后孩子上学你就等着被人看不起"：用羞耻感推动消费或储蓄选择。

**容易误判的反例**：

- 一位律师平静地讲解离婚时财产怎样分割，提醒保留证据。这是风险信息，语气不渲染恐慌。
- "女生 30 岁前一定要做的 5 件保养，最后一件限时优惠"。这是营销，标"无"并在依据里写"营销"。
