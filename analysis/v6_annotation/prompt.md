# D2 LLM 标注提示词（当前 v2，2026-11-07，Zhao Dingcheng）

把 [D1 的定义](narrative_types.md)改写成给 LLM 用的提示词，用于婚恋议题视频的标注，以及双模型核查（D3）。当前版本是 v2，正式文本在 [prompt_v2.py](prompt_v2.py)，下面第 5 节是它的原样副本；v1 保留在 [prompt_v1.py](prompt_v1.py)，供复现。修改提示词时改 `prompt_v2.py`（或新建下一版并改 `make_prompt_md.py` 里的 `CURRENT`），修改说明文字时改 `prompt_md.in`，然后按第 6 节的命令重新生成本文，不要直接编辑本文。

## 1. 怎样使用

`prompt_v2.py` 里的 `SYSTEM`、`TEMPLATE`、`FIELDS`、`parse` 与 [analysis/v6/dual_model_check.py](../v6/dual_model_check.py) 中的同名对象接口相同，可以直接替换：

```python
sys.path.insert(0, "<仓库>/analysis/v6_annotation")
from prompt_v2 import PROMPT_VERSION, SYSTEM, TEMPLATE, FIELDS, parse
```

v2 在原有的 `issue`、`group_label`、`narrative_type`、`genre`、`reason` 之外，多了四个问题字段 `q1_target`、`q2_generalize`、`q3_negative`、`q4_endorse`。D3 的分析脚本只用原有字段，对 v0、v1、v2 的结果都能用；四个问题字段如果也写进 CSV，可以用来分析分歧出在哪一问。`python -I -X utf8 prompt_v2.py` 会自检模板、六个示例和解析函数。

## 2. v1 → v2 改了什么（issue #10）

v1 在同一批 500 条上让 Qwen 判出 51% 群体标签、DeepSeek 只判出 0.6%，分析见 [agreement.md](agreement.md) 第 5 节。v2 针对两个方向分别修改：

| 问题 | v1 的写法 | v2 的做法 |
|---|---|---|
| Qwen 把"对象：……"前缀当套话，494 条里 481 条写"对象：群体" | `reason` 放第一位，以"对象：个人／群体"开头 | 四个问题各成一个字段（`q1_target` 等），先答问题再给标签，`reason` 放到最后；去掉前缀 |
| 婆婆、丈夫、继母被写成"群体" | 只问"对象是不是一类人" | 对象默认是"个人"；角色称呼都算具体人物；只有明确的群体指称或贬义称号才算群体 |
| 标签和四问可能对不上 | 解析只查两条矛盾 | `parse` 检查标签是否由四问的答案推出，不一致就拒绝 |
| DeepSeek 认为"部分女性"不算推广 | 推广要求"都""没一个"这类全称说法 | 泛指一类人的贬义总结也算推广 |
| DeepSeek 把字幕里明说的标签也排除 | "只标视频认同的""描述者的概括不算" | 视频自己的标题、字幕、旁白、博主原话默认认同，除非明确反驳 |
| "批判家暴男"被判成针对男性 | 没有规定 | 按具体恶行定义的人不算性别群体，除非把恶行说成某一性别的普遍特征 |
| DeepSeek 在 v1 下没有判出任何其他三类叙事 | 只强调"有冲突不等于有立场" | 加上正面信号：博主直接给出劝告、评判或结论，就是在表达立场 |
| 示例 | 4 个，其中一个写了"对象：群体（农村出身男性）" | 6 个，加入"夫妻搞笑互动""批判家暴者""字幕说女生只看钱"；示例只给完整 JSON，不给前缀 |

## 3. v0 → v1 改了什么（历史）

| 问题 | v0 / v5 试点 | v1 的做法 |
|---|---|---|
| 单个反派被判成群体标签（v5 试点的主要误报） | 只有一句"只刻画具体人物的选无" | 拆成四个依次回答的问题：对象是不是一类人、有没有推广、是不是负面特征、视频认不认同；任何一个答"否"就是"无" |
| 视频反驳某种标签，也被判成持有它 | 没有规定 | 共同规则：只标视频认同的说法；示例 3 专门演示这种情形 |
| 冲突题材被当作有立场 | v5 的 (c) 直接把冲突算作属性 | 明确"有冲突不等于有立场" |
| 营销内容被判成焦虑渲染 | 只在焦虑渲染的括号里提了一句 | 列为共同规则，依据写"营销"，方便事后统计 |
| 几类同时符合时不一致 | 没有顺序 | 规定顺序：群体标签 → 唯一正确 → 二元对立 → 焦虑渲染 |
| 非性别的群体标签 | 无处可放 | `narrative_type` 记"群体标签"，`group_label` 记"无" |
| 什么时候"无法判断" | 只列出了取值 | 写明条件：描述太短、太乱，或看不出视频是否认同 |
| 先下结论、后找理由 | `reason` 放在最后 | 要求先输出 `reason`，并先写对象是"个人"还是"群体"（v2 撤回了这一改动，见上节） |
| 前后矛盾的输出 | 只检查取值范围 | `parse` 额外拒绝两类矛盾：性别标签不配"群体标签"、`issue` 为"否"却有标签 |

## 4. 需要 Li Yitong 留意的地方

- **解析拒绝**：v2 的一致性检查比 v1 严。API 模型被拒会重试；Qwen 被拒记为缺失。请在 meta 里记录拒绝条数，超过约 2% 告诉我。
- **长度**：模板约 2,950 字，比 v1 长约 870 字；加上最多 1,200 字的描述，估计仍在 Qwen 的 `max_model_len=4096` 以内，但请看一下有没有被截断的提示。输出多了四个短字段，Qwen 的 `max_tokens=250` 应该够用。
- **扩充参照阳性**：`deepseek_label.py enrich` 目前用 v0 提示词。全量标注改用 DeepSeek 后，参照最好和全量标注用同一版提示词（v2），否则校准的是另一套规则。
- **示例**：六个示例都是编写的，不来自视频描述。

## 5. 提示词原文（由 prompt_v2.py 生成）

版本：`PROMPT_VERSION = "v2"`。

**System**

```text
你是严谨的内容分析标注员。只根据给出的视频描述判断，不猜测描述中没有的信息。只输出一个 JSON 对象。
```

**User**（`{cap}` 处填入视频描述，最多 1,200 字；模板中的 `{{`、`}}` 在填入后变成单个花括号）

```text
以下是一条短视频的文字描述（由模型根据视频生成）：
「{cap}」

请按顺序回答下面的问题，最后只输出一个 JSON 对象。

【第 1 步 issue】视频主要内容是否涉及婚恋、夫妻、婆媳、两性关系或家庭中的性别角色。取值："是"/"否"。

【第 2 步 群体标签的四个问题】每个问题单独作答，不要先想结论。
q1_target：视频批评或贬低的对象是谁？
  - 默认是"个人"。婆婆、丈夫、妻子、继母、前任、相亲对象、剧中某个角色，都是具体人物，选"个人"。
  - 只有描述里出现明确指称一类人的说法，才选群体：如"女人""男人""女生们""现在的女孩""某地人"，或"捞女""凤凰男""妈宝男""扶弟魔""普信男"这类称号。指称性别的选"性别群体"，指称地域、年龄、职业等的选"其他群体"。
  - 按具体恶行定义的人（家暴者、出轨的人、骗子），选"个人"，除非视频把这种恶行说成某一性别的普遍特征（如"男人都会家暴"）。
  - 视频没有批评或贬低任何人（温馨、搞笑、记录日常），选"无对象"。
  取值："个人"/"性别群体"/"其他群体"/"无对象"。
q2_generalize：视频是否把负面特征说成这类人共有的？全称说法（"都""没一个"）算；泛指一类人的贬义总结（"现在的女生就是……""有些男人就是……"）也算；用称号解释人物（"一看就是捞女"）也算。q1 不是群体时选"否"。取值："是"/"否"。
q3_negative：归给这类人的是不是人品、能力或动机上的负面特征（如物质、靠不住、心机重、懒）？只说"很难""很累"是诉苦，选"否"。开玩笑的语气不影响判断。取值："是"/"否"。
q4_endorse：视频是否认同这个说法？视频自己的标题、字幕、旁白或博主原话说出来的，默认认同，除非视频明确反驳或嘲讽它；剧中角色的台词，看整条视频是印证它还是纠正它；看不出来选"无法判断"。取值："是"/"否"/"无法判断"。

【第 3 步 group_label】
  - q1 为"性别群体"，且 q2、q3、q4 都是"是"：按被贴标签的性别填"针对女性"或"针对男性"。
  - q1 为"性别群体"，q2、q3 为"是"，q4 为"无法判断"：填"无法判断"。
  - 其他情况：填"无"（q4 为"无法判断"时也可以填"无法判断"）。
  取值："针对女性"/"针对男性"/"无"/"无法判断"。

【第 4 步 narrative_type】只选一类，按顺序取第一个符合的：
  "群体标签"：q1 为"性别群体"或"其他群体"，且 q2、q3、q4 都是"是"时必须选；其他情况不能选。
  "唯一正确"：把一种选择说成唯一正道，同时贬低或否定其他选择。
  "二元对立"：把问题说成只有两个对立的阵营或选项，非此即彼。
  "焦虑渲染"：用恐惧、紧迫感或羞耻感推动一个观点或选择（如年龄倒计时、夸大风险）。
  "无"：以上都不符合。
  博主直接给出劝告、评判或结论（"女生一定要……""千万别……"）时，就是在表达立场，按上面几类判断。只讲冲突、不表态的故事选"无"。商品、课程、婚恋中介等的推销内容选"无"。

【第 5 步 genre】"剧情/段子"（虚构表演、短剧、搞笑段子）/"观点/评论"（博主直接表达看法）/"个人经历"（真人记录自己的生活）/"新闻/普法"/"其他"。

【第 6 步 reason】最后写，不超过 40 字，用自己的话概括依据，不要引用描述原文。

issue 为"否"时，q1_target 填"无对象"，q2–q3 填"否"，q4 填"否"，group_label 和 narrative_type 都填"无"。

【示例】（示例是编写的，不来自真实视频）
- 描述大意：短剧中一名妻子为骗保险金谋害丈夫，最后被警方抓获。
  {{"issue":"是","q1_target":"个人","q2_generalize":"否","q3_negative":"是","q4_endorse":"否","group_label":"无","narrative_type":"无","genre":"剧情/段子","reason":"单个反派，没有说到女性整体"}}
- 描述大意：丈夫偷吃妻子藏的零食被发现，两人互相打趣，配着搞笑音效。
  {{"issue":"是","q1_target":"无对象","q2_generalize":"否","q3_negative":"否","q4_endorse":"否","group_label":"无","narrative_type":"无","genre":"剧情/段子","reason":"夫妻搞笑互动，没有贬低谁"}}
- 描述大意：博主讲述一起家暴案件，批评施暴的丈夫，呼吁受害者及时报警。
  {{"issue":"是","q1_target":"个人","q2_generalize":"否","q3_negative":"是","q4_endorse":"是","group_label":"无","narrative_type":"无","genre":"观点/评论","reason":"批评具体施暴者，没有说男性都会家暴"}}
- 描述大意：婆婆干涉小夫妻生活，字幕总结"嫁给凤凰男就是嫁给他全家"。
  {{"issue":"是","q1_target":"性别群体","q2_generalize":"是","q3_negative":"是","q4_endorse":"是","group_label":"针对男性","narrative_type":"群体标签","genre":"剧情/段子","reason":"字幕用贬义称号概括农村出身的男性"}}
- 描述大意：视频字幕写着"现在的女生谈恋爱，看的只是你兜里有多少钱"，配着男生叹气的画面。
  {{"issue":"是","q1_target":"性别群体","q2_generalize":"是","q3_negative":"是","q4_endorse":"是","group_label":"针对女性","narrative_type":"群体标签","genre":"观点/评论","reason":"字幕把只看钱说成当下女生的共性"}}
- 描述大意：博主列出"男人都靠不住"等网络说法，并逐条反驳。
  {{"issue":"是","q1_target":"性别群体","q2_generalize":"是","q3_negative":"是","q4_endorse":"否","group_label":"无","narrative_type":"无","genre":"观点/评论","reason":"转述标签但立场是反驳"}}

按 issue、q1_target、q2_generalize、q3_negative、q4_endorse、group_label、narrative_type、genre、reason 的顺序输出 JSON，不要输出其他内容。
```
