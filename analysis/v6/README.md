## L1 自下而上抽样（`bottom_up_sample.py`）

从 RecIF 用户历史中均匀抽取 3,000 次曝光（视频按被看到的次数加权），用 Qwen3-30B-A3B-Instruct-2507 判断：社会议题大类、具体议题、是否表达有争议的立场或叙事、叙事类型。2,996 条输出合法。结果：[汇总](results/bottom_up_summary.json)，[逐条标签](results/bottom_up_labels.csv)。这是 LLM 判断，未经人工核查；每个大类只有约 20–160 条，比例的误差约 ±10 个百分点。

| 大类 | 占全部曝光 | 其中表达对立叙事 | 主要叙事类型 |
|---|---:|---:|---|
| 非议题内容（娱乐、美食、游戏等） | 77.7% | — | — |
| 文化与价值观 | 5.5% | 44% | 唯一正确、群体标签、二元对立 |
| 家庭与代际 | 3.6% | 32% | 二元对立、唯一正确 |
| **性别与婚恋** | 3.3% | **63%** | 二元对立、焦虑渲染、唯一正确、群体标签 |
| 消费与经济 | 3.1% | 41% | 焦虑渲染（多为营销视频，需人工核查） |
| 学术与思想 | 1.5% | 24% | — |
| 身体与外貌 | 1.4% | **88%** | 焦虑渲染 |
| 人生选择与出路 | 1.3% | 40% | 唯一正确、焦虑渲染 |
| 其他社会议题 | 1.3% | 55% | 焦虑渲染 |
| 公共秩序与自由 | 0.9% | 62% | 焦虑渲染 |
| 资源与公平 | 0.6% | 53% | 唯一正确 |

读法：约五分之一的曝光涉及社会议题。性别与婚恋占比高、对立叙事比例也高，适合作案例研究；身体与外貌几乎都被判为焦虑渲染；消费类的"焦虑渲染"大多是促销和"赚钱游戏"广告，说明定义需要排除营销内容（交给 D1、D2）。"文化与价值观"量最大，但包含历史等敏感内容，按 v6 不纳入主分析。
