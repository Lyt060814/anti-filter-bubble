# v6 数据脚本与结果（Li Yitong）

在服务器上运行，`results/` 只放视频 ID、标签和汇总数字，不含视频描述原文。

## L1 自下而上抽样（`bottom_up_sample.py`）

从 RecIF 用户历史中均匀抽取 3,000 次曝光（视频按被看到的次数加权），用 Qwen3-30B-A3B-Instruct-2507 判断：社会议题大类、具体议题、是否表达有争议的立场或叙事、叙事类型。2,996 条输出合法。结果：[汇总](results/bottom_up_summary.json)，[逐条标签](results/bottom_up_labels.csv)。这是 LLM 判断，未经人工核查；每个大类只有约 20–160 条，比例的误差约 ±10 个百分点。

| 大类 | 占全部曝光 | 其中表达对立叙事 | 主要叙事类型 |
|---|---:|---:|---|
| 非议题内容（娱乐、美食、游戏等） | 77.7% | — | — |
| 文化与价值观 | 5.5% | 44% | 唯一正确、群体标签、二元对立 |
| 家庭与代际 | 3.6% | 32% | 二元对立、唯一正确 |
| **性别与婚恋** | 3.3% | **63%** | 二元对立、焦虑渲染、唯一正确、群体标签 |
| 消费与经济 | 3.1% | 41% | 焦虑渲染（多为营销视频，需人工核查） |
| 学术与思想 | 1.5% | 24% | — |
| 身体与外貌 | 1.4% | **88%** | 焦虑渲染 |
| 人生选择与出路 | 1.3% | 40% | 唯一正确、焦虑渲染 |
| 其他社会议题 | 1.3% | 55% | 焦虑渲染 |
| 公共秩序与自由 | 0.9% | 62% | 焦虑渲染 |
| 资源与公平 | 0.6% | 53% | 唯一正确 |

读法：约五分之一的曝光涉及社会议题。性别与婚恋占比高、对立叙事比例也高，适合作案例研究；身体与外貌几乎都被判为焦虑渲染；消费类的"焦虑渲染"大多是促销和"赚钱游戏"广告，说明定义需要排除营销内容（交给 D1、D2）。"文化与价值观"量最大，但包含历史等敏感内容，按 v6 不纳入主分析。

## L1b 用 DeepSeek 重标同一批 3,000 条（`deepseek_label.py bottomup`）

v0 核查显示 Qwen 系统性高估（见 [analysis/v6_annotation/agreement.md](../v6_annotation/agreement.md)），所以用 DeepSeek V4 Pro 和一份跨大类的提示词重标（`BU_TEMPLATE`，加入 D1 的共同规则：只算视频认同的立场、冲突不等于立场、营销排除）。2,973 条输出合法。结果：[逐条标签](results/bottomup_ds_labels.csv)、[meta](results/bottomup_ds_meta.json)。第 4 节以这一版为准，Qwen 版作为"开源模型高估"的对照。

| 大类 | 占全部曝光（DeepSeek） | 其中表达对立叙事 | 同一大类（Qwen） |
|---|---:|---:|---:|
| 非议题内容 | 92.6% | — | 77.7% |
| 性别与婚恋 | 1.8%（54 条） | 20% | 3.3%、63% |
| 文化与价值观 | 1.7%（51 条） | 24% | 5.5%、44% |
| 家庭与代际 | 1.3%（38 条） | 11% | 3.6%、32% |
| 公共秩序与自由 | 0.5%（16 条） | 12% | 0.9%、62% |
| 身体与外貌 | 0.5%（16 条） | 25% | 1.4%、88% |
| 消费与经济 | 0.4%（13 条） | 23% | 3.1%、41% |
| 人生选择与出路 | 0.4%（13 条） | 8% | 1.3%、40% |
| 其他、资源与公平、学术与思想 | 0.7%（20 条） | 5% | — |

读法：按 DeepSeek，约 7% 的曝光涉及社会议题（Qwen 判为 22%），议题内表达对立叙事的比例在 8%–25% 之间（Qwen 为 31%–88%）。两个模型在大类上的一致率为 83%，差异主要是 Qwen 把很多普通内容判成了议题和立场。每个大类样本很少（13–54 条），比例的区间很宽。
