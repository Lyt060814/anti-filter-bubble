## 怎样看和排练

用浏览器（Chrome 或 Edge）直接打开 `slides.html`：

| 按键 | 作用 |
|---|---|
| → / 空格 / PageDown，← / PageUp | 下一页 / 上一页（也可以点屏幕右侧或左侧） |
| 1–9，Home，End | 跳到对应页 |
| N | 显示或隐藏讲稿（页码、讲者、本页时长、到哪一秒结束） |
| T，R | 打开计时器；R 把计时器清零 |
| F | 全屏 |

## 怎样改

每页是一个 `<section class="slide" ...>`，改的时候注意三处要一致：

1. **讲者**：`data-speaker="全名"`。右下角显示的讲者姓名就取自这里，guideline 要求每页显示讲者全名。
2. **讲稿**：`<script>` 里的 `const NOTES={"1": "...", ...}`，键是页码。
3. **时长**：`const CUM=[0, ...]` 是每页的**累计结束时间**（秒），长度要等于页数加 1。增删页或调整时长后要一起改。

## PR 流程

1. 拉取最新 `main`，新建自己的分支：`<名字>/slides-<主题>`，例如 `junbo/slides-4-5`。
2. **只改自己负责的页**（`<section>`、对应的 `NOTES` 条目）。需要改别人的页、全局样式或 `CUM` 时，在 PR 里说明。
3. 页里每个数字都要能在 [report/sections](../report/sections/) 里找到出处，并标出证据类型（Measured / Derived / Scenario / Proposed）。示意数字要标 *Illustrative*。
4. PR 描述写清改了哪几页，附一张改后的截图，再写自己计时的结果。
5. 大家都改同一个 HTML 文件，冲突在所难免。先合并的人不用等；后提交的人先 `git pull --rebase origin main`，再解决冲突。
6. 不要放视频描述原文、账号截图或服务器地址（仓库是公开的）。

导出成 PDF 的方法还没定。文件没有打印样式，直接打印大概只会得到当前页。在地址后面加 `?static`（例如 `slides.html?static`）可以跳过动画，直接显示每页的最终状态，适合逐页截图或导出。导出后要逐页检查字体和图片有没有丢失。
