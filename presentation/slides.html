05 — Theory
What each action can move
PROPOSITIONS 1–4 · REPORT §3.3
01 · FEEDBACK · PROP. 1
ΔV = η·c
The same quantity builds a cocoon and takes one apart. The sign of η is the platform’s choice, not yours.
02 · TOPIC CONTROLS · PROP. 2
ΔV = 0
“Show less of this topic” and every category-based check cannot change the mix inside the topic.
03 · FILTERS · PROP. 3
ΔV = log(1−TPR)/(1−FPR)
Acts on what reaches the screen — the one action that needs no cooperation from the recommender.
No user action reaches the platform layer Λ — it is added for everyone, before any personalisation (Prop. 4).
