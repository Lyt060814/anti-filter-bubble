# anti-info-bubble

COMP1110 (HKU, 2026/27 Sem 1) group project on information cocoons / filter bubbles (信息茧房).

**Current working topic (draft, to be confirmed by the team):**
*Can You Tap Your Way Out? An Outside-In Audit of Xiaohongshu's Anti-Cocoon Controls* — once a fresh Xiaohongshu account is narrowed into a single-interest lifestyle cocoon, do the platform's official "cocoon-breaking" tools actually restore feed diversity, and does it last?
